《礼记·乐记》里有一段对话。孔子与弟子宾牟贾谈论《大武》——那部据说歌颂武王伐纣的乐舞。宾牟贾对演出的细节提出疑问：为什么开头要长时间击鼓而不动作？为什么舞者要向右踏脚？孔子逐一作答，讲到武王的事迹、士卒的疲惫、周公与召公的治理。

这段文字之所以重要，不是因为它记录了《大武》的真相，而是因为它暴露了一件事：**到战国秦汉之间，人们已经不能直接看懂《大武》了。** 一部国家级乐舞，需要靠师徒问答来解释每一个动作的含义。音乐一旦脱离了它生长的制度，就迅速变成需要注释的文本。

西周的制度，就是那个"生长环境"。

## 一、礼乐不是「音乐加礼仪」

今天说"礼乐"，容易理解成"礼仪场合用的音乐"。这个理解太轻了。

西周的礼，是一套**区分**的技术：天子、诸侯、卿、大夫、士，每一个等级在器用、服饰、宫室、车马、祭祀、宴享上都有规格。乐的加入不是为了好听，而是为了让这套区分**可听、可见、可执行**。鼎的数目是给眼睛看的，编钟的架数和舞队的行数是给耳朵和眼睛同时看的。

所以礼乐的核心不在旋律，而在**配置**：谁可以用几面乐队，谁可以跳几行舞，谁可以听什么调。这是一套用声音执行的政治制度。

> 边注｜「礼乐」作为一个合成词，在先秦文献中的用法并不统一。西周金文里看不到「礼乐」二字连用的制度性表述，我们今天熟悉的「制礼作乐」叙事，主要来自《左传》《国语》《礼记》等后世文献。这一点在本章第九节会展开。

## 二、六代乐舞：一部被追认的历史

西周宫廷保留着六部大型乐舞，后世称"六代乐舞"：

| 乐舞 | 所系之帝 | 被叙述的内容 |
|---|---|---|
| 《云门》 | 黄帝 | 云气与德化 |
| 《咸池》 | 尧 | 施泽于民 |
| 《大韶》（箫韶） | 舜 | 绍继尧德，以箫为主奏 |
| 《大夏》 | 禹 | 治水之功 |
| 《大濩》 | 商汤 | 救民于旱 |
| 《大武》 | 周武王 | 伐纣建周 |

这六部的排列本身就是一部政治史：从传说时代到当代，每一个朝代留下一部乐舞，周人把它们全部接管，用来证明自己是这条谱系的合法终点。

要注意的是：**前五部几乎不可能以原貌存在。** 商代以前的乐舞，周人只能通过口头传说与仪式记忆来重构；《大韶》在孔子那里已经是被赞叹的"古乐"，而不是可以随意演出的曲目。六代乐舞的实质，是**用音乐写成的朝代序列**，它的历史真实性在各部之间差异极大。

> 边注｜《大韶》在后世的地位极高。孔子在齐听到《韶》，据《论语》记载，他沉浸其中，很久尝不出肉的滋味。这个细节常被当作"古乐感人之深"的证据，但它更可能说明的是：孔子听到的是一场精心复原的演出，而"沉浸"是一种态度表达。

## 三、《大武》：六成结构

六代乐舞中，只有《大武》留下了较详细的结构描述。《礼记·乐记》说它"六成"——六个段落。综合先秦文献的零散记载，大致可以拼出这样的骨架：

1. **第一成**：长时间击鼓，舞者持盾而立，象征武王待诸侯之至。
2. **第二成**：舞者发扬蹈厉，象征灭商；有"再成而灭商"之说。
3. **第三成**：向南进军，象征平定南方。
4. **第四成**：平定南方诸国，舞队变化。
5. **第五成**：分职而治，周公左、召公右。
6. **第六成**：舞者皆坐，象征秩序成立、天下安定。

这个结构值得注意的地方有三点。

第一，**它是叙事的**。六成不是六个情绪段落，而是一条时间线：备战、决胜、南征、分治、安定。中国大型乐舞"以结构叙事"的传统，从这里开始。

第二，**它极度依赖视觉**。舞者的队列、动作方向、持械姿势，承担了大部分表意功能。音乐在其中起什么作用，文献几乎没有交代——这本身就是一个重要信息：先秦对乐舞的记录，重"容"而轻"声"。

第三，**它被不断重新解释**。同一部《大武》，孔子说它"尽美而未尽善"——形式完美，但内涵有欠缺，因为其中含"杀伐之气"。这句评价把艺术判断与道德判断绑在一起，成为此后两千年中国音乐批评的基本语法。

## 四、乐官：一个技术官僚系统

《周礼·春官》记载了一套庞大的音乐职官体系。撇开其中的理想化成份，它至少反映了战国人所理解（或设想）的西周音乐分工：

- **大司乐**：总掌乐政，负责教国子、主持大型祭祀乐舞。
- **乐师**：掌国学之政，教小舞。
- **大师、小师**：掌律吕、教瞽矇（盲乐师）诵诗。
- **瞽矇**：盲人乐师，掌弦歌、诵诗、听声辨律。
- **典同**：掌管乐器音高的校定。
- **磬师、钟师、笙师、镈师、籥师、旄人、鞮鞻氏**：分掌各类乐器与乐舞。

这套分工有两个特点值得停下来看。

**其一，专业分工极细。** 钟、磬、笙、籥各有专官，说明乐器已经高度专门化，演奏需要长期训练。

**其二，盲人乐师占据核心位置。** 瞽矇掌弦歌与诵诗，而且"听声辨律"被当作他们的专长。这不是偶然：在缺乏精确记谱的时代，音乐的保存依赖记忆，而盲人乐师群体正是记忆的载体。中国早期音乐的知识传承，很大程度上是通过一个特定的人群完成的。

> 边注｜「瞽」在先秦不只是生理描述，也是一种职业身份。盲乐师常与史官并列，参与政治劝谏——他们通过诵诗与奏乐，把历史与规范带进宫廷的日常。音乐在这里同时是艺术、档案与舆论。

## 五、教育：国子之学

西周的贵族教育，内容是"礼、乐、射、御、书、数"六艺，乐占其一。但"乐"在其中的具体内容，比今天想象的复杂：

- **乐德**：中、和、祗、庸、孝、友——通过乐来培养的品德。
- **乐语**：兴、道、讽、诵、言、语——与乐相关的语言能力，包括如何引诗、如何讽谏。
- **乐舞**：从《云门》到《大武》，按年龄与等级依次学习。

注意"乐语"这一项。它说明西周的音乐教育不只是演奏训练，还包括**在政治场合正确使用诗乐的能力**：什么时候引哪句诗，怎样用诗表达不同意见。这是外交与谏议的技术，而音乐是它的载体。

这一点与古希腊形成有趣的对照：希腊的 mousike 也承担公民塑造，但希腊的落点在"性格"（ethos），西周的落点在"分寸"（礼）。一个关心人会变成什么样的人，一个关心人在什么场合说什么话。

> 分歧｜「乐」在西周教育中的地位，文献记载与实际情况可能差距很大。六艺之说主要见于《周礼》与《礼记》，西周金文与《诗经》早期篇章并未提供如此整齐的教育体系。更稳妥的说法是：西周贵族确实接受音乐训练，但"乐德、乐语、乐舞"三分，很可能是战国儒者对理想教育的整理。

## 六、乐队与舞佾：声音的等级

礼乐制度最赤裸的部分，是它对"规模"的规定。

**乐队排列**（据《周礼·春官·小胥》）：

| 等级 | 排列 | 说明 |
|---|---|---|
| 天子 | 宫县 | 四面悬挂，如宫室之墙 |
| 诸侯 | 轩县 | 三面（缺北面） |
| 卿大夫 | 判县 | 两面 |
| 士 | 特县 | 一面 |

"县"即"悬"，指悬挂编钟编磬的架子。四面、三面、两面、一面，是一个可以用眼睛数出来的等级表。

**舞佾**：天子八佾（八行八列，六十四人），诸侯六佾，大夫四佾，士二佾。同样是一眼可数的规格。

《论语·八佾》记载，孔子得知季氏在自家庭院里用了八佾，反应极为激烈，认为这种事都能容忍，还有什么不能容忍。他愤怒的对象不是"音乐难听"，而是**规格被僭越**——一个大夫用了天子的配置，等于在声音里宣称自己等同于天子。

> 边注｜这也解释了为什么中国古代对"僭乐"的处罚往往重于对"俗乐"的排斥。俗乐是品味问题，僭乐是政治问题。前者可以禁，后者必须罚。

## 七、八音：中国最早的乐器分类

西周乐器已经多到需要分类。《周礼》提出"八音"，按**材质**划分：

| 类 | 材 | 代表乐器 |
|---|---|---|
| 金 | 青铜 | 钟、镈、铙、钲 |
| 石 | 玉石 | 磬、编磬 |
| 土 | 陶 | 埙、缶 |
| 革 | 皮革 | 鼓、鼗 |
| 丝 | 弦 | 琴、瑟 |
| 木 | 木 | 柷、敔 |
| 匏 | 葫芦 | 笙、竽 |
| 竹 | 竹 | 箫、篪、管、籥 |

这个分类法与西方的"Hornbostel–Sachs"（按发声方式分：体鸣、膜鸣、弦鸣、气鸣）不同。八音分的是**材料**，而材料在中国古代不只是物理属性，还连着方位、季节、五行与政治秩序。金声玉振，不只是音色搭配，也是一套宇宙论的听觉表达。

八音的分类影响极长：直到清代，宫廷乐器仍然按八音陈列。它是中国音乐分类学的起点，也是"音乐即秩序"这一观念的物证。

## 八、钟磬与音律：技术那条线

制度讲完了，还要看技术。西周音乐最惊人的成就，在青铜里。

西周编钟从早期的三件一组，逐步发展到八件一组。更关键的是**一钟双音**：同一口钟，敲击正鼓部与侧鼓部，可以发出相隔大三度或小三度的两个音。这意味着一个八件组的编钟，实际可用的音位远多于钟数。

这项技术在西周中晚期已经出现，到战国早期的曾侯乙编钟达到顶峰——六十五件钟，总音域五个半八度，钟体与钟架上的铭文记录了曾国与楚、齐、晋、周等国律名的对应关系。**它证明先秦的乐律学不是靠文献推测的，而是有实物与铭文支撑的精密知识。**

与钟相伴的是律学。三分损益法——以弦长或管长的 2:3 与 4:3 交替相生——在《管子·地员》中用于生成五音，在《吕氏春秋·音律》中推至十二律。十二律的完整律名（黄钟、大吕、太簇、夹钟、姑洗、仲吕、蕤宾、林钟、夷则、南吕、无射、应钟）最早完整见于《国语·周语下》伶州鸠答周景王问，时在春秋末年。

> 分歧｜西周编钟的音阶结构，学界有不同解读。一种意见认为西周钟多用"四声"（宫、角、徵、羽）而不见"商"音，另一种意见认为这是统计与测音方法造成的印象。这个争论看似技术性，实则关系到"中国五声音阶何时定型"这一大问题。本章不裁断，只标注：涉及西周钟的音阶结论，都应视为待核。

## 九、周公制礼作乐：史实还是建构

这是本章必须正面处理的问题。

传统叙述是：武王灭商后不久去世，成王年幼，周公摄政，制礼作乐，奠定了周代八百年的制度基础。这个叙述见于《左传》《礼记》《史记》，也是后世儒家的核心历史叙事。

但现代学术提出了几个难以回避的困难：

1. **西周金文没有"制礼作乐"的记载。** 大量西周青铜器铭文涉及册命、征伐、赏赐、诉讼，却没有一份描述礼乐制度的建立。
2. **《周礼》的成书年代有争议。** 主流意见认为它成书于战国，甚至可能晚至汉初，其中包含大量理想化的制度设计。用它来复原西周，等于用后世的图纸反推前世的房子。
3. **"周公"其人的历史形象，经过了层层叠加。** 从西周的执政者，到战国的制度设计者，到汉代的圣人，每一层都添加了新的内容。

比较稳妥的结论是：西周确实存在一套与等级配合的乐舞制度（金文中的"射""飨""大室"等场合与乐器组合可作旁证），但这套制度是否由周公一次性"制作"，以及它的具体条文是否如《周礼》所载，都应当持保留态度。

> 边注｜这不等于说礼乐是虚构的。制度可以真实存在，而它的"起源故事"是后世建构的——这两件事经常同时为真。本书的处理办法是：讲制度时用考古与金文，讲观念时用文献，两者分开标注。

## 十、采诗与《诗经》：雅乐的另一半

礼乐不只用于祭祀与朝会，也用于日常的宴饮与外交。这些场合需要一个曲目库，而《诗经》就是那个曲目库的歌词部分。

《诗经》分风、雅、颂。传统解释是：风为地方民歌，雅为朝廷正乐，颂为宗庙祭祀之乐。这个三分既是内容的分类，也是**音乐用途**的分类——《墨子》等文献提到"诵诗三百，弦诗三百，歌诗三百，舞诗三百"，说明同一批诗可以有不同的表演方式（诵、弦、歌、舞）。

关于"采诗"制度，传统说法是周代设有采诗之官，收集民间歌谣以观风俗。这个说法同样缺乏西周的直接证据，但《诗经》中大量民歌的存在，说明宫廷确实吸收过地方歌谣。

> 听｜《诗经》的曲调一首也没有留下来。今天所谓的"诗经歌曲"（如宋代朱熹《仪礼经传通解》所载《风雅十二诗谱》、明代《魏氏乐谱》中的相关曲目）都是后世的拟作，不是先秦的原貌。听这些音乐时，请把它们当作"后人如何想象《诗经》"，而不是"《诗经》如何演唱"。

## 十一、崩塌：礼崩乐坏与郑声

西周末年，王室东迁（前 770 年），礼乐制度的物质基础随之瓦解。诸侯强盛，僭越成为常态，这就是后世所说的"礼崩乐坏"。

但"礼崩乐坏"这个说法容易误导。它暗示了一种从有序到混乱的衰退，实际情况更像是**音乐的重心转移**：宫廷雅乐还在，但新起的俗乐更受欢迎。魏文侯对子夏说，他听古乐就犯困，听郑卫之音就不知疲倦——这段话被儒家反复引用，作为"人心不古"的证据，但它同时是一份珍贵的听众报告。

雅乐为什么不好听？原因可能很具体：它的旋律缓慢、重复、以钟磬为主，功能是标记仪式进程，而不是取悦耳朵。俗乐则节奏鲜明、旋律婉转、有情感起伏。**当音乐不再承担标记等级的职责，它自然要承担别的职责。**

这场转移奠定了中国音乐史上一个长期张力：**雅与俗**。此后每一次音乐变革——汉魏乐府、隋唐燕乐、宋元戏曲、明清小曲、近代学堂乐歌、当代流行——都可以看作俗乐进入主流、再被雅化、再被新的俗乐冲击的循环。

## 十二、本章要点

1. 礼乐的实质是用声音标记等级，核心在配置（几面乐队、几行舞队、何种乐器），不在旋律。
2. 六代乐舞是用音乐写成的朝代序列；除《大武》外，各部几乎不可能以原貌存在。
3. 《大武》六成是叙事性结构，视觉成分重于听觉成分，这影响了中国乐舞的记录传统。
4. 西周乐官体系分工极细，盲乐师（瞽矇）是音乐记忆的主要载体。
5. 八音按材质分类，其背后是材性与秩序的对应，不是声学分类。
6. 西周编钟的一钟双音是实物证据，使先秦乐律学不必只靠文献推测。
7. "周公制礼作乐"应分层处理：制度可能存在，起源叙事是后世建构。
8. 礼崩乐坏的实质是音乐重心从仪式转向娱乐，由此开始"雅俗"这条贯穿三千年的主线。
