1808 年 12 月 22 日，维也纳河畔剧院的一场学院音乐会拖了四个多小时。节目单排得很满，一首没有标题的新[[symphony|交响曲]]夹在其中；同场还听到了第六《田园》交响曲、第四钢琴协奏曲与《合唱幻想曲》。乐队刚坐定，第一个音就砸了下来：三个短音紧跟一个长音，强奏，没有引子，没有铺垫。听众甚至来不及安静，这几个音已经把速度、调性和整部作品的气息一并交代完毕。

这部作品后来编为作品 67 号，c 小调，四乐章，也就是今天说的第五交响曲。它不到四十分钟，却在此后两个世纪里被反复拿来回答同一个问题：一部没有歌词、没有画面的器乐作品，凭什么让人听出一段完整的事？答案藏在它使用的最寻常的工具里——[[sonata-form|奏鸣曲式]]、四个乐章的调性布局，以及一个短到只有四个音的动机。本章的分析接 m3-29《奏鸣曲式：把调性矛盾立起来，再解决掉》的规则，史线见 m1-34《贝多芬：站在古典的边界上》，作曲家专章见 m4-06。

## 一、创作背景：一首夹在长节目单里的新作

这部交响曲的写作跨度是 1804 到 1808 年，四五年间[[beethoven|贝多芬]]（Ludwig van Beethoven，1770—1827）还在同时写别的作品：第三交响曲《英雄》完成于 1803—1804 年，钢琴奏鸣曲《热情》写于 1804—1805 年。也就是说，那个四音动机和一部更长的钢琴奏鸣曲，出自同一段精力最集中的时期。1808 年末，他把这首 c 小调交响曲交给了自己筹划的那场学院音乐会——那是面向买票公众的场合，节目单上一首新作并不比另一首更特殊。作品题献给洛布科维茨伯爵与埃斯特哈齐亲王，他们当时是贝多芬在维也纳的重要支持者。

首演当晚的听众听到的不是一部「巨著」，而是四个乐章，中间大概还夹着别的曲目。当时的评论对它的反应并不一致：有人被开头那种不加礼貌的强奏弄得措手不及，也有人只把它当成又一部写得挺热闹的交响曲。把这件事放在具体处境里看很重要——交响曲在那时还没有后来那种近乎仪式性的地位，它是一场晚会里的一个节目。这部作品之所以能被听成「一部关于挣扎与胜利的作品」，是后来几十年的接受史慢慢加上的，不是 1808 年当晚就自带的说明。

耳聋是这段时间绕不开的背景。贝多芬大约在 1796—1798 年间开始出现听力问题，1802 年在海利根施塔特写下一封给弟弟们的信，承认自己可能永远听不见；那封信没有寄出，是他死后才被发现的。写第五交响曲时，他三十多岁，听力已在持续恶化，作为钢琴家公开演出的路正在关闭，作曲成了越来越主要的工作。这里只能说处境相关，不能把耳聋当成作品风格的直接成因；一个听不见的人并不会自动写出更深刻的东西。

## 二、作曲家：一个把草稿当战场的人

只需了解与这部作品有关的几面。贝多芬到维也纳后曾跟海顿学过一段时间，古典的交响曲、奏鸣曲、四重奏框架是他继承而来的起点，不是他要推翻的东西。他和海顿、莫扎特的关键差别，是处理这些框架的方式：同样用奏鸣曲式，他把它当成一场可以不断延长冲突的戏剧，而不是一次布局清楚的陈述。

现存草稿本显示，他为开头那几个音反复推敲过很久。一个听起来像是随手抓来的动机，在纸上被换过音高、换过节奏、换过配器，试过怎样把它塞进低声部、怎样让它从圆号上冒出来。这件事改变了我们对「灵感」的理解：那四个音之所以显得不可替代，不是因为它是某次天赐，而是因为它足够短、足够有弹性，经得起反复拆装。一个太完整的旋律反而没有这种可塑性。

> 边注｜把耳聋与作品深度直接挂钩，是最常见的误读。听力丧失改变的是贝多芬的生活：他放弃演奏生涯，社交圈缩小，越来越依赖纸笔交流。间接的影响可能在于，当耳朵不再可靠，他只能更依赖头脑中的声音结构来检验作品。但「听不见」本身不产生任何音乐质量——它只是把这位作曲家逼进了一个只能向内走的位置。

写作这件作品的几年里，他的身份也在变：不再靠某个宫廷的固定岗位，而靠出版、年金、音乐会与教学维持独立。这让他可以写不为某个具体场合服务的音乐——一首交响曲不必对应某场晚宴，它可以对应一个抽象的过程。第五交响曲正是这种独立性的产物：它的叙事不指向任何外部事件，只指向音乐自己立起来的矛盾与解决。

## 三、作品结构：四个乐章的时长与调性布局

全曲四个乐章，按「快—慢—快—快」排列，第三乐章已经用谐谑曲取代了贵族小步舞曲。先看一张可核对的表。时长占比按常见录音估算，不同指挥的速度、以及是否演奏呈示部反复，会让第一乐章差出两分钟左右；表中给的是区间，不是定值。

| 乐章 | 速度与拍号 | 调性 | 曲式 | 大致时长占比 | 核心材料 |
|---|---|---|---|---|---|
| 一 | Allegro con brio，2/4 | c 小调 | 奏鸣曲式 | 约 24—28% | 三短一长动机 |
| 二 | Andante con moto，3/8 | 降 A 大调 | 主题与变奏（两主题交替） | 约 25—28% | 进行曲式主题与歌唱主题 |
| 三 | Allegro，3/4（谐谑曲） | c 小调，中段 C 大调 | 谐谑曲—三声中部 | 约 16—19% | 动机的三拍子变形 |
| 四 | Allegro—Presto，4/4 | C 大调 | 奏鸣曲式（加长[[coda|尾声]]） | 约 28—32% | 号角式主部与第三乐章回忆 |

全曲通常在三十三到三十六分钟之间。第三乐章最短，末乐章最长——这不是随手排的，而是把分量压在了终点。第二乐章虽然慢，却并不短：它用近九分钟做了两件主题的交替变奏，承担的不是休息，而是把冲突暂时搁置后的重新积蓄。

> 边注｜「时长占比」这种数字很容易被误当成作品属性。它其实同时取决于三件事：乐谱写出来的长度、演奏者选的速度、以及是否反复。第一乐章若省略呈示部反复，能短掉近一半的呈示时间，占比立刻从四分之一掉到五分之一以下。所以这张表描述的是常见的演奏形态，不是乐谱的绝对尺寸。

调性布局是另一条骨架，值得单独列出来横着读：

| 位置 | 调性 | 在做的事 |
|---|---|---|
| 第一乐章呈示部 | c 小调 → 降 E 大调 | 立起主调，再去关系大调另立一处 |
| 第一乐章再现部 | c 小调 | 副部搬回主调，把矛盾结清 |
| 第二乐章 | 降 A 大调 | 离开冲突地带，气息放缓 |
| 第三乐章 | c 小调／中段 C 大调 | 暗流中先露出一线明亮 |
| 第四乐章 | C 大调 | 同名大调的终点 |

两行 c 小调与 C 大调的对照，是全曲最容易被听出的结构事实：同一个主音，换了调式，色彩完全反转。这种「小调出发、同名大调收束」的走法，后来成了十九世纪交响曲最常见的叙事模板之一。

## 四、各乐章内容：主题怎样出现、变形、收束

第一乐章。呈示部的主部就是那四个音，由弦乐与部分木管齐奏；随后连接部把它模进、推高，带向降 E 大调。副部进入前，圆号先用动机的节奏敲出一句号角式的预告，弦乐才接过一支较舒展的旋律——这是全曲第一次有真正「歌唱」的地方。结束部在降 E 大调站稳。[[development|展开部]]把动机拆成更小的碎片，在木管、弦乐、铜管之间接力，转到关系疏远的调上，低音长时间悬在属音不落地。[[recapitulation|再现部]]把主部与副部依次搬回 c 小调，同一句副部旋律由明转暗。尾声没有立刻收话，而是把四个音重新拆开、推高，几乎又展开了一次，最后以 c 小调的强奏落定。

第二乐章。两支主题交替出现：先是一支进行曲式的旋律，步伐整齐、以级进为主，在降 A 大调；紧接着一支更歌唱的旋律，音域更宽、线条更长。它们轮流变奏，有时主旋律被藏进低声部，有时被快速的音符群包住，有时由木管单独陈述。中间有一段变奏转入同主音小调，色彩骤暗，是全乐章最内省的时刻；随后回到降 A 大调。结尾的尾声把开头主题重新铺开，以安静的和弦收束。

第三乐章。谐谑曲用 3/4 拍，c 小调，快速的音流由低声部率先冲出，四个音的节奏骨架藏在细碎音型里——不是原样引用，而是换了一副面貌。三声中部转入 C 大调，有一段模仿式的对位，明亮但短暂，很快被谐谑曲的再现盖过。这个乐章末尾并不真正落幕：一段过渡把听众直接送进末乐章，两乐章之间没有可以鼓掌的停顿。

第四乐章。C 大调的号角式主部一上来就把前三乐章的阴郁翻转；副部在 G 大调，旋律更圆润。展开部把主部与连接材料反复拆装，转调频繁。再现部把副部搬回 C 大调。乐章中后段有一处第三乐章谐谑曲主题的短暂折返，像回头看了一眼，随即被新的推进盖过。此后是加长的尾声：短笛、低音大管与三支长号加入，音域向两端撑开，力度层层抬升，以 C 大调的整齐和弦收束。

## 五、主要音乐主题：轮廓与节奏型

第一主题即「命运动机」。音高上，前三个音停在同一高度反复，第四个音向下落一个小三度并延长；节奏上是短—短—短—长，三个等长短音后接一个明显更长的音；力度为强。它短到不像旋律，更像信号，而下行小三度恰好是最容易唱准、也最容易器乐化的音程之一。

呈示部副部的轮廓与它相反：圆号先以动机的节奏预告，弦乐随后唱出的旋律以级进和小幅跳进为主，长音多、气息宽。它不是用性格反差来对抗主部——两者都带着动机的影子——而是用节奏密度和音区把对比做出来。

第二乐章两主题：第一支级进、方正、近乎进行曲，重音落在规整的位置；第二支音域更宽，起落更柔，音符时值更长。前者像说话，后者像唱歌。变奏进行时，这两支旋律的轮廓保持不变，改变的是谁在奏、在什么音区奏、周围包着什么音型。

第三乐章主题：低声部快速上行、音型细碎，但三拍子的强弱骨架始终清楚；三声中部主题改为级进上行的歌唱线条，配器转薄。末乐章主部是 C 大调的分解和弦式号角，上行、开阔、节奏整齐；副部在 G 大调，旋律更圆润，句法也更长。

> 分歧｜这四个音到底「是」什么，历来有两种读法。十九世纪以来的一种读法把它解释为命运敲门，进而把全曲讲成人与命运的抗争；另一种读法拒绝任何故事，只把它当作一个极短的节奏—音程细胞，全曲的价值在于它怎样被拆装、转调、重新配器。前一种读法的权威依据来自贝多芬助手辛德勒的转述，而辛德勒的谈话册后来被查出篡改，其转述的可靠性因此存疑；「命运」这个称呼也不是作曲家所加，作品出版时只有调号与作品号。本章倾向于把后一种读法作为分析起点，同时承认前一种读法确实抓住了这部作品最容易被听出的戏剧性——它解释了为什么听众愿意接受这个绰号。

## 六、旋律与节奏：一个细胞怎样长成全曲

这个动机的节奏是不对称的：三短一长，在 2/4 拍的强拍上开始。三个短音造成急于向前的分裂感，长音把能量收住，形成一个不可再分的单元。人耳对这种不均等极敏感——规整的四分音符容易滑过去，三短一长却像敲门一样留下印记。音高方面只用同音重复和一个下行小三度，材料节省到近乎吝啬，却因此能被塞进任何声部、任何调。

旋律层面的写法并不靠花腔。第一、第三、第四乐章的主题大多由短小、可重复的单元拼成，方便被拆开再拼回去；真正的长线条集中在第二乐章，而它也被变奏反复拆散。全曲的速度布局是快—较慢—快—更快，末乐章由 Allegro 推进到 Presto。值得注意的是，没有一个乐章真正慢到静态：第二乐章的从容是相对于其余三个乐章而言，它内部仍有持续的节奏脉动。

音域的安排也服务于同一目的。主部主题集中在中音区，便于齐奏时保持整齐；变奏与展开时它被移到高音区变得尖锐，或压到低音区变得笨重，同一个轮廓因此显出不同性格。第二乐章的音域最宽，两支主题一低一高交替，等于把「说话」与「唱歌」放在不同楼层；末乐章则把两端同时打开，短笛向上、低音大管向下，音域与配器在这里一起制造终点的重量。

节奏型在四个乐章里不断变形。谐谑曲把三短一长塞进三拍子的快速音流，长音被压缩成音型的落点；末乐章把长音改成整齐的号角节奏，动机由「敲门」变成「宣告」。听者以为自己听到了新主题，其实是同一副骨架换了衣服。这种变形比原样重复更难写，也更耐听——它让统一性不显得机械。

## 七、和声与配器：调性的冲突与乐器的增减

第一乐章的调性路线是古典奏鸣曲式的常规：小调主部在 c 小调，副部去关系大调降 E 大调。副部回主调时，靠的是属—主的解决把副部搬回 c 小调，呈示部留下的那笔账就此结清。展开部大量使用模进与远关系转调，低音长时间停在属音上，制造「马上要解决却迟迟不解决」的悬置。第二乐章整体在降 A 大调，中段那次同主音小调的转色彩变奏，是全曲和声上最暗的一笔。

第三、第四乐章的关系最直接：c 小调的谐谑曲后面接同名大调的末乐章；第三乐章中段短暂亮到 C 大调，像提前给出的预告。同名大小调只差第三个音，色彩却从压抑翻成明亮——这是全曲最有说服力的调性叙事，不需要任何文字说明就能被听出来。

配器是可数的，不必用「丰富」打发。基准编制是双管木管（长笛、双簧管、单簧管、大管各两支）、两支圆号、两支小号、定音鼓与弦乐组。开头四个音用齐奏，把音色压成一个平面，块面感极强；展开部让动机在各组之间接力，音色成了标记材料去向的路标。末乐章临时加入短笛、低音大管与三支长号，把音域两端同时撑开，铜管的重量在尾声层层加码。定音鼓在展开部与尾声的重击，则把节奏骨架直接敲给听众。

和声的功能逻辑也值得点一句：全曲的关键转折几乎都落在属—主的关系上——展开部把属和弦悬住，再现部才让它落地；第三乐章中段那次 C 大调的闪现之所以像预告，正因为它是末乐章主和弦的提前现身。终止式的落点因此不只是收尾，而是叙事的句号。

## 八、聆听重点：带着标记去听

不同录音的差别值得先说清。常见的现代交响乐团录音弦乐组人数多、铜管用现代活塞乐器，音响饱满、衔接平滑；若想听更接近十九世纪编制的音响，可以找弦乐组较小、使用自然铜管或早期乐器的版本，开头四个音的齐奏会更干燥，木管的棱角更清楚。这里不提供音频，只给出版本特征与段落标记；下面按一支保留呈示部反复、速度偏中庸的第一乐章（约七到八分钟）标注，实际分钟数会有出入，段落标记比分钟数可靠。

> 听｜0:00 四个音齐奏，先只记长短比例；约 1 分钟 副部在降 E 大调出现，圆号已先用动机节奏预告；约 3 分钟 展开部开始，追踪同一材料被转到哪些调、低音是否长时间悬住；约 5 分钟 再现部，副部改在 c 小调；最后约 1 分钟 尾声再次拆动机，别急着鼓掌。第二乐章开头注意两支主题如何交接；第三乐章末尾注意那个把人直接送进末乐章的过渡；末乐章中后段留意谐谑曲主题的一闪而过，以及长号加入后音量的台阶。

一个实用的听法是把四个音当成全曲的节拍器：每当觉得「主题不见了」，就去找那个三短一长的轮廓，它多半换到了别的声部或别的调上。能追住这条线，四个乐章就会从四段音乐变成一段有前后因果的叙述。

## 九、艺术价值：它解决了前人没解决的问题

器乐套曲怎样统一，是海顿、莫扎特之后真正摆在桌上的难题。他们靠调性布局与主题呼应把四个乐章连起来，已经相当成熟；这部作品给出的办法更激进：用一个短到只有四个音的动机细胞，加上一条从 c 小调到 C 大调的调性弧，把四个乐章绑成因果链。统一不再靠「听起来像」，而靠「是从同一颗种子长出来的」。

第二个贡献是奏鸣曲式的戏剧化。展开部被拉长、推远，再现部之前的悬置更久；尾声从收话变成第二战场，材料在已经解决之后再次被拆开推高。这一改动的实质，是把曲式从布局的工具变成制造经历的工具——听众不只是确认「矛盾解决了」，而是被要求经历解决的过程。第三个贡献是用谐谑曲替换小步舞曲：第三乐章不再是社交场合的舞曲，而成为整部戏剧里暗流涌动的一环，并直接通向末乐章。

还有一点常被忽略：全曲没有任何标题或文字说明，却让几代听众从中听出了「从黑暗到光明」的叙事。这不是作曲家写进乐谱的指令，而是调性布局、动机变形与力度曲线共同产生的效果。它把「绝对音乐」能承载的意义推到了当时的边界，同时没有跨过那条边界去写标题音乐。

## 十、历史影响：可指认的几条线

最直接的一条是调性叙事。勃拉姆斯第一交响曲同样从 c 小调走到 C 大调，终曲的分量也被刻意加重——这是最能被指认的回应。布鲁克纳、马勒的交响曲把末乐章写成全曲的重力中心，也延续了这条路。至于谐谑曲取代小步舞曲，十九世纪的交响曲大多照办，它几乎成了标准的四乐章配置。

第二条是「主题作为种子」的做法。柏辽兹《幻想交响曲》用一个固定乐思贯穿全曲，李斯特把主题变形发展成一套方法，瓦格纳把它系统化为主导动机。这些做法都不等于照抄那四个音，但把它们串起来的共同前提——一个短小的材料可以统摄一部大型作品——在这部交响曲里得到了最有力的示范。

第三条属于接受史。二战期间，英国广播公司用「短短短长」的节奏作为胜利信号的听觉标识，因为它正好对应摩尔斯电码里代表 V 的三点一划。一个 1808 年的器乐动机，被借去充当二十世纪的公共符号，这比任何评论都更具体地说明了它的传播广度。

> 边注｜把 BBC 的用法说成作品「本意」，是典型的倒果为因。那是一次借用：借的是节奏的辨识度，不是音乐的内容。作品在 1808 年没有、也不可能有这层含义。接受史的事实可以写，但不能反过来改写作曲家的意图——这一点和「命运敲门」的追认是同一个道理。

## 十一、本章要点

1. 作品写于 1804—1808 年，1808 年 12 月 22 日在维也纳的一场长节目单音乐会上首演，同场还有《田园》交响曲等新作。
2. 开头是三个同高短音加一个下行小三度的长音，节奏为短短短长；「命运敲门」的说法来自辛德勒的转述，属追认且不可靠。
3. 四乐章为快—慢—谐谑—快，调性从 c 小调经降 A 大调、c 小调／C 大调，最终落到 C 大调。
4. 第一乐章把奏鸣曲式戏剧化：展开部拉远，再现部把副部搬回 c 小调，尾声成为第二展开部。
5. 四个音以变形而非原样重复的方式贯穿全曲，谐谑曲与末乐章里都能找到它的骨架。
6. 第二乐章由两支主题交替变奏，中段一次同主音小调的变奏是最暗的时刻。
7. 配器的变化可数：双管编制为底，末乐章加入短笛、低音大管与三支长号，把音域两端撑开。
8. 它的贡献在于用单一动机加调性弧统一套曲、把谐谑曲变成戏剧环节，并在无标题的情况下让调性叙事被听见。
9. 可指认的影响包括勃拉姆斯第一交响曲的同名大小调路线、十九世纪交响曲的谐谑曲配置，以及动机作为种子被后世系统化。

下一部作品把镜头从维也纳的剧场移到一支高音小号上：当「主题」还没有被当成种子，巴洛克协奏曲靠什么让全曲站住——这是《勃兰登堡协奏曲》第二号要回答的问题。
