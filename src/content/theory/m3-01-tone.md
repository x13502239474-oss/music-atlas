一支音叉被敲响，声音又细又直，像一根线悬在空气里，久久不散。调音师把它贴到钢琴的铁板上，同一个高度从钢琴里涌出来，却裹着一层说不清的「厚度」。两支声音的高一样，你绝不会把它们认成同一种东西。

音叉是调音师最信得过的东西，因为它只给一个音，而且这个音几乎不游移。它上面往往刻着一个数字，比如「440」，意思是每秒振动四百四十次。整个乐理体系，就建立在这种可以被重复、被测量的声音之上。

这层「厚度」就是本章要拆开的第一件事。音乐不是从抽象的音符开始的，而是从这种具体的声音开始的。要在纸上写音乐，先得分清楚：我们写的到底是声音的哪一部分。

## 一、一支音叉能说出声音的几件事

把敲响的音叉放在耳边，再换成钢琴、再换成小鼓，差别立刻冒出来。人耳对声音的辨别，可以拆成四件事，乐理里叫**音的四种性质**：高低、长短、强弱、音色。它们不是四种声音，而是同一个声音的四个侧面——任何一个声音都同时具备这四项，就像任何一件东西都有长、宽、高和重量一样。

| 性质 | 问的问题 | 物理上对应什么 | 音乐里怎么用 | 怎么听出来 |
|---|---|---|---|---|
| 高低 | 尖还是沉 | 振动频率（每秒振动次数） | 旋律、音程、调 | 音叉与低音提琴的差异 |
| 长短 | 拖多久 | 振动持续的时间 | 节奏、音符时值 | 一记钟声慢慢消散 |
| 强弱 | 响还是轻 | 振幅（振动的幅度） | 力度、节拍重音 | 同一音轻弹与重弹 |
| 音色 | 是谁在响 | 泛音的成分与比例 | 区分乐器、人声 | 钢琴与音叉同高度却不同「厚度」 |

第一项**高低**由频率决定。频率越高听上去越尖，越低越沉。人耳大致能听到每秒二十次到两万次之间的振动，钢琴最低的键约每秒二十七次，最高的约四千一百八十六次，正好落在听觉范围的中间一段。音叉上刻的数字就是它的频率，比如「440」表示每秒振动四百四十次。乐理里说的「音高」，指的就是这一项。

第二项**长短**是声音持续的时间。它不决定音高，只决定这个音在时间里占多大一块。一记钟声敲完，音高没变，余音却慢慢消散——长短在变，高低没变。写字时把音的长短记下来，就成了节奏。第三项**强弱**是振幅，也就是振动幅度的大小：幅度大听着响，幅度小听着轻。同一个音用不同力气弹，高低与音色都不变，只有强弱在变。

第四项**音色**最难说清，却最容易被认出来。钢琴和音叉弹同一个高度，音高完全一样，我们仍能一口分辨，靠的就是音色。原因是：音叉几乎只发出一个频率，而钢琴每弹一个键，都在同时发出一串频率——最低的那个叫基音，决定我们听到的音高；上面那一串叫泛音，它们的多少和强弱比例，就是音色的物理来历。不同乐器的泛音配方不同，于是我们闭着眼也能分清钢琴和小提琴。

> 边注｜把音叉按在共鸣箱上，声音会突然变响——这是共振放大了振幅，改变的是强弱，不是音高。这个细节常被误当成「音变高了」，其实高度一点没动。乐器制造里大量利用共振：小提琴的琴箱、吉他的琴筒、钢琴的共鸣板，做的都是同一件事——把弦那点微弱的振动放大到能传满音乐厅。

把四项分开看，还能明白记谱到底记了什么。五线谱主要记高低与长短——音符写在哪条线上决定音高，写成什么形状决定时值；力度记号记强弱；乐器的名称与演奏法记音色。一套乐谱能把前三项写得相当精确，第四项却只能靠文字提示和演奏者的判断。这也是为什么同一份谱子在不同人手里会响得不一样：谱子固定了音高、时值与力度，音色那一份留给了活人。

这四项里，高低是本章的主角。长短会在节奏那一章展开，强弱会并入力度与节拍，音色则在讲乐器与配器时再回来。接下来所有的音名、音组、音域，都是在给「高低」这一项建立坐标。

## 二、音乐只要「乐音」吗，鼓和钹算什么

先做一个听感实验：敲音叉，声音有一个明确的「哆」；再敲小鼓，你听不出它「唱」的是哪个音。前者叫**乐音**，后者叫**噪音**。教学上最省事的区分是：乐音有固定音高，噪音没有固定音高。乐音的振动是规则的、周期性的，所以耳朵能抓住一个稳定的高度；噪音的振动杂乱无章，耳朵抓不住任何一条线。

但这条线并不像听上去那么干净。定音鼓能调音，鼓面绷紧一点、放松一点，敲出来的音高会跟着变，所以在乐队里它常被认为「有音高」。锣与钹虽然音高模糊，作曲家仍会指定大小与厚薄，因为它们的高、低倾向确实会影响音响的重量。小鼓、沙锤、三角铁则明显没有固定音高，是典型的噪音类打击乐器。同一件长笛，气流稳时是乐音，掺进气声时又带上了噪音成分。

> 分歧｜乐音与噪音的界限，是乐理入门第一处口径之争。传统教材按「发音体是否规则振动」把声音一分为二：规则的是乐音，不规则的是噪音。二十世纪的作曲实践却把噪音正式写进作品，声学也指出绝大多数乐器发出的都是复合音，界限并不在物理上天然存在。本章的立场是：这不是一个靠定义就能解决的是非题，而要看要做什么——写旋律时用有固定音高的乐音，写节奏时噪音同样合法。两种口径各有各的用处，僵持不下反而会挡住初学者。

这个界限在别的音乐传统里更不构成问题。京剧的武场以鼓板、大锣、小锣、钹为主，其中多数没有固定音高，却承担了整出戏的节奏骨架与情绪转折。演员的唱、念、做、打都要踩在锣鼓点上，去掉武场，戏就散了。可见「噪音不重要」只是从写旋律的角度看才成立；换成以节奏组织场面的角度，同一批声音立刻成了核心材料。

二十世纪有一派作曲家干脆把环境里的各种声响直接当作材料，录下来、剪接起来做成作品。在那样的音乐里，「噪音算不算音乐」这个问题已经被实践回答了。但在传统的乐理体系里，我们讨论的音名、音程、调式，仍然只适用于有固定音高的那一类声音。本章采用一种实用的教学口径——以「有没有固定音高」为主，兼顾听感，把能明确唱出音高的算作乐音，把抓不住高度的归到噪音一侧。

这个区分还有个实际后果：它决定了哪些声音能被「记」下来。一段旋律可以写成一串音名，因为每个音都有确定的高度；一阵掌声却写不成音名，只能写成人声效果或节奏标记。所以乐理教材先讲乐音，不是因为噪音不重要，而是因为乐音这套工具有一套可以写下来的坐标，噪音暂时没有。

这个区分决定了本章的范围。下面讨论的音名、音组、音域，只适用于有固定音高的声音。

## 三、七个字母为什么够用

现在给高低定名字。全世界通行的办法，是用七个拉丁字母循环标记：**C、D、E、F、G、A、B**。它们叫**音名**。念作「哆、来、咪、发、索、拉、西」时我们进入了另一套系统，那是唱名，先放一放。音名像人的姓名，唱名像小名；同一个人可以有不同小名，但姓名只有一个。

七个字母之所以够用，是因为音乐把高低排成一个圈：从 C 往上数到 B，再往上一个又回到 C，只是更高了。这个「更高一轮」就是八度——两个音相隔八度时，听上去像同一个音在高处照了一遍镜子，既像又不像。于是一个简单的办法成立：同一轮用七个字母，跨一轮就在字母上做标记。钢琴的白键反复重复 C D E F G A B，黑键则夹在中间，用升降记号命名。

黑键的命名藏着一个有意思的事实。C 与 D 之间那个黑键，既可以叫「升 C」——把 C 抬高半音；也可以叫「降 D」——把 D 降低半音。同一个键，两个名字，音高却完全一样。这种「同名不同写、同音不同名」的现象叫等音，初学时会觉得多余，到了讲调号与转调时才发现它处处都在。升降记号的形状也由此而来：升号像被抬高了一截的竖线，降号像被压弯的符号，还原号则把它们拉回本位。

> 听｜圣桑《动物狂欢节》里的《天鹅》与《大象》很适合现在听。前者由大提琴唱出一条窄幅起伏的旋律，后者让低音提琴在低音区笨重地跳跃。两首都只用七个字母里的几个音，靠音区与音色就把形象立住了。听的时候只盯一件事：旋律是不是在这七个音里打转，而没有跑出这个圈。

音名在各国还有不同的写法。英美体系用这里的 C D E F G A B，德国体系把 B 写成 H、把降 B 写成 B，法国体系则把这七个字母直接对应到唱名。看到德文乐谱里的 H，别以为是印刷错误——它就是我们的 B。这套差异在跨国读谱时才显出来，初学者知道有这回事即可，不必现在就记。

音名是坐标，不是音高本身。写下「C」，你只说出了它在循环里的位置，还没说它是哪一轮的 C。要让坐标唯一，得加上「轮数」。

## 四、同一个 C 为什么有八个

把 C 的每一轮排成一列，就得到**音组**。钢琴上从低到高依次是：大字二组、大字一组、大字组、小字组、小字一组、小字二组、小字三组、小字四组、小字五组。总共九组，但两端都不完整——最低的大字二组只有几个音，最高的小字五组也只到 c⁵，所以完整出现的 C 大约有八个，这就是「同一个 C 有八个」的说法来历。

标记方法是：大字组的音用大写字母（C），小字组用小写字母（c），小字一组写成 c¹（也常写成 c'），小字二组写成 c²，以此类推。

| 音组 | 标记 | 在钢琴上的位置 | 听感 |
|---|---|---|---|
| 大字一组 | C₁ | 键盘最左端一带 | 低沉、浑厚 |
| 大字组 | C | 低音区 | 厚，余音长 |
| 小字组 | c | 中低音区 | 男声常见音域 |
| 小字一组 | c¹ | 键盘接近正中 | 女声与旋律常用 |
| 小字二组 | c² | 中高音区 | 明亮 |
| 小字三组 | c³ | 高音区 | 尖细 |

钢琴一共八十八个键，其中白键五十二个、黑键三十六个。白键按七个字母循环，黑键嵌在白键之间，按两三个一组的规律排列。你只要找到那组「两个黑键」和那组「三个黑键」，就能在键盘上认出所有的 C：两个黑键左边的白键就是 C。

音组的两端并不整齐。最低的大字二组只有从 A₂ 起头的几个音，最高的小字五组也只到 c⁵ 为止，所以「九个组」是名义上的划分，不是每组都占满七个音名。这一细节不影响我们使用音组，却提醒我们：音组是人为画出的格子，键盘本身是连续的。格子画在哪里，取决于约定，不取决于物理。

有了音组，音名才成为唯一地址。说「c¹」和说「c²」，谁都不会弄错——它们相隔一个八度，是键盘上隔了七个白键的两个不同位置。这也是为什么乐理要先讲音名、再讲音组：前者给出姓氏，后者给出门牌号。

> 边注｜大写与小写这套写法来自德语习惯：德文里大写的 C 与小写的 c 读作不同的音名，两组在键盘上音高也差一个八度。中文教材沿用「大字组／小字组」的说法，正是把这套德式分组翻译过来的结果。看到 c¹ 的上标，别以为是数学幂次，它只是「小字第一组」的简写；写成 c' 是另一种同样通行的写法。

## 五、中央 C 在哪里，一个手指找得到的坐标

现在回答开头那个问题：中央 C 是哪个 C？它是**小字一组的 c**，写作 c¹。在钢琴上，它就在键盘正中央附近——准确说，在最靠近中央的那组 C 里，位于两个黑键组左侧的那个白键。你把右手食指放在键盘正中偏左，摸到一组两个黑键，紧挨其左边的白键就是它。

中央 C 之所以重要，不是因为它「在中间」，而是因为它给了全键盘一个可触摸的原点。它的频率约为 261.6 赫兹，这个数字以 A4=440 赫兹的国际约定为前提；历史上标准音高并不统一，同一个 c¹ 在不同年代、不同地区可能高一点或低一点——巴洛克时期的常见标准比今天低，十九世纪某些乐队的调得更高。直到二十世纪，A4=440 才被固定为通行标准。频率是物理事实，音名是人为约定——这句话值得记住。一个乐音的身份，一半在振动里，一半在我们共同遵守的规则里。

在纸上，中央 C 也有固定位置：高音谱表的下加一线，低音谱表的上加一线。这两条线都叫「加线」，是临时写在五线谱上下的短线；中央 C 恰好夹在两张谱表之间，好像一座桥。写五线谱时会直接用到这一点，现在只需知道有这个「两面都能找到的同一个音」。钢琴谱常把高、低两行谱表上下对齐，中央 C 正好落在两行之间，左右手各按一次，听起来是同一个高度。

> 听｜把音叉与钢琴上的 c¹ 连着听一遍：先敲音叉，听它单薄、稳定、几乎不带起伏；再弹钢琴的同一个键，听它饱满、有厚度、还拖着一点余音。两者高度相同，差别全在泛音与延音。这个对照比任何定义都更快地讲清「音高相同、音色不同」是什么意思。

## 六、八十八个键画出多大的地图

把全部乐音按高低从最低排到最高，就得到**音域**。这个词的用法有两种：一是指整个乐音体系的总范围，二是指某一件乐器或某一个人的声音能覆盖的范围。钢琴从最低的 A₂ 到最高的 c⁵，一共八十八个键，是常见的音域最宽的乐器之一。人声就窄得多，通常两个八度上下，训练有素的歌手也难超过三个。

人声按音域分成若干声部：女声由高到低是女高音、女中音、女低音，男声是男高音、男中音、男低音。作曲家写合唱时，必须知道每个声部能唱到多高、多低，写超了就没人唱得出来。乐器同理：长笛适合高音区，大提琴适合中低音区，把一段旋律硬搬到不合适的音区，轻则失去特色，重则根本吹不响、拉不出。

音域再往下切，就是**音区**——高音区、中音区、低音区。音区不是音名，而是听感上的分区，就像人声分男女高低。同一条旋律挪到不同音区，性格会变：挪高变得紧张明亮，挪低变得厚重阴暗。民歌里常见的现象是，同一支曲调在不同地方由不同人唱，音区一变，整个情绪就跟着变。作曲家选择音区，本质上是在选择情绪。

回到刚才那首《动物狂欢节》：大象用低音提琴在低音区踱步，天鹅用大提琴在中音区滑行，而同组里的《鸟笼》让长笛和弦乐在高音区快速窜动。三首曲子用的音高材料没有本质差别，换的就是音区与音色，听众却读出三种完全不同的动物。这说明音区不是装饰，它本身就在表达。

音名、音组、音域、音区，四件事合起来，已经能把任何一个乐音钉在确定的位置上。这套位置系统有一个正式的名字。

## 七、为什么需要给所有音画一张地图

前面建立的整套坐标——有固定音高的音、七个循环的字母、按组区分的八度、从低到高的总范围——合起来叫[[tone-system|乐音体系]]。它就是我们给声音画的地图：地图上的每一条经纬，对应一个可以被反复找到、被写在纸上的音。

说得更具体一点：乐音体系只收有固定音高的音，所以第二节把小鼓、沙锤那一类隔了出去；它把音按八度分层，所以同一个字母可以在不同高度重复；它给每一层编号，所以「c¹」在全球只有一个位置。这三条规定，是后面一切记谱、音程、调式的前提。没有它们，「旋律升高了」这句话就没有客观意思——升高多少？从哪个 c 到哪个 c？全靠这套地图才有答案。

理解乐音体系，最容易犯的错误是把它当成「所有能听见的声音」。它不是。它是被挑选、被编号、被约定好的一套材料——音乐用这套材料盖房子，但材料本身并不等于房子。风声、雨声、机器声都不是这套地图上的点，它们可以进入某些作品，却进不了音名与音组的表格。

还要留意：这套地图只管每个音在循环里处于什么位置，不管相邻两个音之间的「距离」是否均匀。把八个 C 排开，谁都知道它们相隔八度；可把 C 到高一个八度的 C 之间切成十二份，每一份该切得多均匀，就是另一回事了。这件事留到下一章——它正是钢琴「调不准」的根源。

这套坐标在生活中的用处比想象中直接。有人说「这首歌太高，唱不上去」，说的其实是音域：最高音超出了他的嗓音范围。把它降两个音，就是整体移到更低的音组；歌手说「降调」，技术上的含义正在这里。再比如给合唱排版，女高音与男低音之间隔着不止一个八度，作曲家必须让两条旋律各自落在舒服的位置，还要在中间填上合适的声部。这些判断全都依赖本章建立的坐标。

## 八、同一串字母为什么有两套叫法

讲到这里，细心的读者会发现一个裂缝：我们说 C 念「哆」，可唱歌的人也会说「哆」，两者是一回事吗？不一定。这里藏着两套教学系统。

一套叫**固定唱名法**：不管在什么调里，C 永远念「哆」，D 永远念「来」。它的好处是音名与唱名一一对应，看见谱就能唱出固定音高，学乐器的人大多用这套。另一套叫**首调唱名法**：把当前调的主音念成「哆」，其他音按它与主音的距离排下去。同一条旋律从 C 挪到 G，在固定唱名法里唱名不变，在首调唱名法里整条旋律的唱名都要重新排一遍。它的好处是唱起来符合调性的听感，唱歌和教和声的人常偏爱它。

> 分歧｜两套唱名法之争，在中国乐理教学中延续了很多年，至今没有统一。固定唱名派强调「音高绝对、读谱稳定」，首调唱名派强调「调性感清楚、便于歌唱」。本章倾向于认为：这不是对错问题，而是目标问题——器乐读谱宜用固定，视唱与和声听觉宜用首调。读者见到「哆」字，先问一句「这是哪一套」，能省掉大量误解。两套系统争的是「怎么念」，不是「有哪些音」；它们共享同一个乐音体系，共享同一套音名与音组。

判断自己该用哪一套，有个简单的标准：如果你面对的是乐器谱，需要按固定位置弹出声音，固定唱名更直接；如果你在视唱一条有明确主音的旋律，想唱出它的调性色彩，首调唱名更顺口。初学者可以先固定一套用熟，再了解另一套，不必一开始就把两套混着学。两套叫法同一个地图，混淆多半不是因为音乐本身复杂，而是因为我们在不同课堂里用了不同名字。把「音名是地址、唱名是叫法」这句话记住，这一节的争论就收敛了。

## 九、本章要点

1. 音有四种性质：高低、长短、强弱、音色；任何一个声音都同时具备这四项。
2. 高低由频率决定，音色由泛音成分决定；音叉「直」而钢琴「厚」，差别在泛音，不在音高。
3. 乐音有固定音高，噪音没有；二者之间是连续地带，本章以「有无固定音高」为主、兼顾听感。
4. 七个音名 C D E F G A B 循环使用，跨一轮就是八度；同一个黑键可叫升 C 也可叫降 D。
5. 音组给音名加上轮数：大字组用大写，小字组用小写，小字一组写作 c¹。
6. 中央 C 是小字一组的 c¹，约 261.6 赫兹（以 A4=440 为前提），在键盘正中附近，高音谱表下加一线、低音谱表上加一线。
7. 音域是能覆盖的高低总范围，音区是其中的高、中、低分段；同一旋律换音区会改变性格。
8. 乐音体系是有固定音高的音经过分层、编号而成的坐标系统，是一切记谱与和声理论的地基。
9. 固定唱名法与首调唱名法争的是读谱与歌唱的口径，不是音本身；见到「哆」先问是哪一套。

音的材料已经备齐。可一旦要把这些音真正排进时间里，就碰到一个绕不开的问题：钢琴上每个音的位置是定死的，可这些位置之间的距离真的「准」吗？下一章就从一台怎么调也调不准的钢琴讲起。
