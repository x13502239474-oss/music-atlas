把一段 C 大调的旋律放在谱架上，从头到尾几乎都是白键——Do、Re、Mi、Fa、Sol、La、Si。可弹到第三小节，谱面上突然冒出一个小小的升号，贴在 F 的前面。手指移到右上方的黑键，声音亮了一下，又很快滑回 Sol。这个升号不在调号里，只在这一小节出现一次；它像一句话里突然抬高或压低的一个字，说完就过去了。本章就从这样一个「多出来的音」开始：它叫什么、从哪里来、到哪里去，又能把音乐变成什么样。

先把键盘当地图。C 到右边的黑键是半音，黑键到 D 也是半音；E 与 F 之间没有黑键，它们本身就差半音。于是一个八度被切成十二个相等的半音，黑白键交替排满其间。可在谱子上，C 右边那个黑键有时写成升 C，有时写成降 D——同一个键，两个名字。名字不同，意味着它在音乐里的「身份」和「去向」不同，这正是变音记号值得专门学的原因。本章先讲单个变化音，再讲把它们排成一列队形的半音音阶，最后看浪漫主义作曲家如何靠这些音把音乐推向新的表情。

## 一、为什么同一个音能「既升又降」

写在音符前面、把音高升高或降低半音的记号，叫[[accidental|变音记号]]。常用的有五种：升号把音升高半音，降号把音降低半音，还原号取消之前的变化、把音拉回白键，重升号升高一个全音，重降号降低一个全音。它们写在音符的左侧，读谱时先看到记号，再决定按哪个键。

记号的作用有范围。临时写在音符前的升降号，只管它所在小节里这个音高的音——同一小节后面同样音高的音也跟着变，但一过小节线就失效，除非连音线把音拖到了下一小节。还原号的作用是把已经被调号或前面临时记号改变的音恢复过来。因此看到谱面上一个还原号，不要以为它「降了音」，它可能只是把一个升高的音拉回原位。

落到键盘上，升 F 与降 G 是同一个黑键，按下去声音完全一样。音高相同、记谱与意义不同的两个音，叫等音。既然声音一样，为什么还要分两个名字？因为记谱承载的不只是音高，还有这个音「从哪来、往哪去」。在 C 大调里，升 F 是走向 G 的导音，它的写法告诉演奏者：这个音要「往上走」；若写成降 G，读者的第一反应反而是它该「往下落」到 F。同一个黑键，两种写法，两种心理预期。

这层区别在独奏钢琴上不太明显——反正按同一个键——但在乐队里就很实在。弦乐手看到升 F 和看到降 G，手指会放在不同的弦位、不同的把位上，运弓的方向和力度也不相同；记谱因此会影响音色和表情，而不只是纸面上的符号差异。初学阶段先记住一句话：变音记号既改音高，也改方向。

## 二、调号里的升降号与临时升降号不是一回事

谱子开头、紧跟在谱号后面的升降号叫调号。它规定整首作品中哪些音要升高或降低，是全曲通用的「底色」。G 大调的调号是一个升号（升 F），F 大调的调号是一个降号（降 B），C 大调没有升降号。调号里的升号写在五线谱固定的线或间上，顺序固定——先升 F、再升 C、再升 G，依此类推；降号则先降 B、再降 E、再降 A。这个顺序不是随便排的，它对应着五度关系，后面讲调号时还会回来。

临时升降号则写在小节中间某个音符前，只管这一小节。在 C 大调里写升 F，只在这一小节有效；下一小节的 F 又回到白键。若你把 F 大调谱子里的降 B 当成「变化音」，就会误判——降 B 写在调号里，是这调的家常音，不是临时冒出来的客人。读谱的第一步永远是先看调号定底色，再看临时记号定改动；顺序反过来，就会把常驻音听成意外。

把这条规矩落到音响上：F 大调的旋律里 B 一律按降 B 弹，整首曲子都带一层柔和的暗色，这是调号给的。若某小节突然写一个还原 B，那个音会「亮」一下——因为它临时离开了调号规定的底色。反过来，C 大调里突然冒出的升 F，也因为打破了白键的常态而显得突出。变化音之所以有表情，前提正是它「不属于这里」：听众心里有那个白键的常态，偏离才有意味。

> 边注｜临时记号遇到小节线就失效，这条规矩有一个常见例外：连音线把音从这一小节拖到下一小节时，记号仍然有效，因为那是同一个持续的音，不是新的起音。还有一种容易看错的情况——同一小节里先写升 F，后面又写还原 F，还原号把前面的升高取消掉，再往后的 F 就回到白键。读这类谱子要养成习惯：从小节开头一路扫过去，随时更新每个音「此刻」的状态。

## 三、升四级与降七级：哪些音最常被改动

一个[[mode|调式]]的七个音按全音、半音的固定顺序排好，构成自然音阶；在这个基础上把某一级音升高或降低半音，得到的音就是[[chromatic|变化音]]，也叫调式变音。注意它与上一章讲的转调不是一回事：转调换了主音、换了整个调性中心，调式变音则主音不变、调性不变，只改动其中一两个音。打个比方，转调是搬家，变化音是给家里的某一面墙换颜色。

哪些音最常被改？以 C 大调为例，排在前面的是升高的第四级（升 F）、降低的第七级（降 B）、降低的第二级（降 D）和降低的第六级（降 A）。升高的第一级、第五级也有，但少见，多用作经过音——短暂路过，不停留。为什么集中在这些级？答案在「倾向」两个字上：改动通常是为了让某个音更强烈地走向它的目标。

先看升四级。大调里第四级到第五级原本是全音（F 到 G），把第四级升高半音，两者之间变成半音，第四级就成了第五级的导音——它像被磁铁吸住一样「想往上走」。试着在琴上弹 C—升 F—G，那个升 F 明显带着一股推力，非落到 G 才踏实。这就是升四级最常被改的原因：它给音乐装了一个指向属音的推进器。

再看降七级。大调的第七级到主音本来是半音（B 到 C），这个半音让第七级有强烈的归家感；把第七级降低半音（降 B），到主音变成全音，归家的拉力被削弱，声音一下子柔和、暗淡下来。弹 C—B—C 与 C—降 B—C 对比，前一句明快、有收束感，后一句带一层说不清的惆怅——降七级就是这样把大调染上小调色彩的。

| 原音级（C 大调） | 常见调式变音 | 改动后的音程关系 | 听感与去向 |
|---|---|---|---|
| 第四级 F | 升 F | 到第五级 G 由全音变半音，成为导音 | 强烈向上解决到 G |
| 第七级 B | 降 B | 到主音 C 由半音变全音 | 张力减弱，色彩转暗 |
| 第二级 D | 降 D | 到主音 C 成为半音 | 向下滑入主音，带叹息感 |
| 第六级 A | 降 A | 与第四级 F 构成小三度 | 借来小调色彩，变柔和 |
| 第一级 C | 升 C | 到第二级 D 成为半音 | 罕用，多作经过音 |

这张表里的「去向」不是规定，而是听觉习惯。作曲家当然可以让升四级不解决——但听众已经形成了期待，故意不满足它，就成了制造紧张的手段。变化的力量，恰恰来自那份被记得的常态。

## 四、把八度填满：半音音阶怎样排出来

变化音用得越来越多，七个自然音就不够用了。把十二个半音从低到高依次排满一个八度，就得到半音音阶。在钢琴上从 C 开始，白键黑键一个不落地按到高八度的 C，弹出来的正是它——首尾连起来共十三个音，其中首尾是同一个音名的高八度。半音音阶的每一步距离都相等，都是半音，因此它像一把刻度均匀的尺子。

它与前面学过的调式音阶有本质区别。自然大调的音阶是「全、全、半、全、全、全、半」——全音与半音不均匀，正因为不均匀，才产生主音的引力与调式的性格。半音音阶步步相等，没有哪个音天生更「像家」，它是平等的、没有重心的。这个差别决定了两者的用途：调式音阶用来建立调性，半音音阶用来模糊调性、连接调性、或者单纯作为一串色彩材料。

半音音阶的用途大致有三类。作为旋律材料，它提供半音进行——相邻两音走半音，是最紧的旋律连接；作为和声材料，它把自然音阶里的空隙填满，让作曲家能取用更多音高；作为转调通道，连续的半音可以平滑地滑向任何新调，因为每个音都可能成为下一个调的成员。上一章讲的转调，若借半音音阶做桥梁，过渡会格外顺滑。

落到音响上，一段很长的半音上行听起来会持续「攀爬」、越来越紧张，因为每一步都不稳定，没有可以歇脚的全音；半音下行则像不断下沉，张力一步步卸掉。电影配乐里常用半音上行铺垫紧张、追赶与不祥，靠的就是这份无处落脚的感觉。听者未必说得出原理，身体却已经绷紧了。

## 五、和声半音阶：按和弦的需要选音

把十二个半音排成音阶，写法不止一种，最常见的是和声半音阶与旋律半音阶。先讲和声半音阶。它的原则是：以自然大调为基础，在原来相邻两音是全音的地方插入一个半音，而且上行与下行用同一套音——叫作「同形」。

以 C 大调为例，自然音阶里 C—D、D—E、F—G、G—A、A—B 这五处是全音，各插入一个半音后，从 C 到高八度 C 依次是：C、升 C、D、降 E、E、F、升 F、G、降 A、A、降 B、B、C。注意这里写成降 E 而不是升 D，写成降 A 而不是升 G——因为降 E、降 A 与功能和声里的和弦音名一致，读谱和想和弦时更方便。同样，降 A 与降 B 分别借自和声大调的降低六级与降低七级，升 F 是属和弦的导音：每个插入音都能在和弦里找到位置，这正是「和声」半音阶这个名字的由来。

为什么说它「为和弦服务」？因为和声半音阶的结构来自和声大调与和声小调的音高资源。大调借用降低六级（降 A）与降低七级（降 B），得到更暗的和弦色彩；小调借用升高七级，让导音出现、属和弦更明确。把这些借用来的音按半音顺序排开，就得到上面那条音列。它上下行同形，是因为和弦不论旋律往哪走都需要同样的音可用。

> 边注｜和声半音阶的写法在教材之间并不完全统一：有的以大调为基础、上下行同形，有的强调小调的升六级而给出另一套音名，还有的在上行与下行取不同的音。本章采用国内通用教材的口径——以大调为基础、上下行同形，并在 frontmatter 的 verify 中标出这一分歧。读者若翻到写法不同的书，先看清它「以哪个调为基础、上下行是否同形」，差异就能对上，不必当成谁对谁错。

## 六、旋律半音阶：上行与下行为什么写法不同

旋律半音阶的原则与和声半音阶相反：它不优先照顾和弦，而照顾「唱起来顺、听起来有方向」。做法是上行时一律用升号，下行时一律用降号，主音和属音保持原来的写法不动。于是同一条半音音阶，上行和下行用两套不同的音名——叫「不同形」。

以 C 为例，上行依次是：C、升 C、D、升 D、E、F、升 F、G、升 G、A、升 A、B、C。下行依次是：C、B、降 B、A、降 A、G、降 G、F、E、降 E、D、降 D、C。把它们并排放，差别一目了然：上行把每个黑键写成「某音的升高」，下行把同一个黑键写成「某音的降低」。按下去是完全相同的键，读谱时却感受到相反的方向。

为什么这样安排？因为升号自带「往上走」的倾向，降号自带「往下落」的倾向。上行旋律写成升号，每个音都轻轻推着下一个往上；下行旋律写成降号，每个音都被拉向下方。半音进行本来就没有全音那种明确的落脚点，方向感全靠记谱与音名的暗示来支撑——旋律半音阶正是用音名给声音「标了箭头」。

| 比较项 | 和声半音阶 | 旋律半音阶 |
|---|---|---|
| 主要服务对象 | 和弦与功能和声 | 旋律的方向与顺口 |
| C 上行写法 | C 升C D 降E E F 升F G 降A A 降B B C | C 升C D 升D E F 升F G 升G A 升A B C |
| C 下行写法 | 与上行相同 | C B 降B A 降A G 降G F E 降E D 降D C |
| 上下行是否同形 | 同形 | 不同形 |
| 主音与属音 | 保持原位 | 保持原位 |

> 听｜找一段电影配乐里常见的弦乐半音上行（紧张铺垫的典型手法），注意声音怎样一步步收紧；再听肖邦《夜曲》里那些半音下行的装饰音，感觉像一声声叹息。两者按的都是同样的黑白键，方向感却完全相反——这就是上行用升号、下行用降号在音响上的对应。

## 七、一个变化音怎样改变整句的表情

变化音的表情功能可以分成三层：色彩、倾向、结构。先说色彩。大调里降低三级、六级、七级，会让它染上小调的阴影；小调里升高六级、七级，会让它明亮起来。这种「向对面借一个音」的做法，让同一调式内部有了明暗变化，而不必真的换调。听众感到「这里忽然暗了一下」，却说不出哪里有变化——正是变化音在悄悄起作用。

再说倾向。升四级、升七级这类被「导音化」的音，制造的是解决的需求：它们悬在那里，要求走到目标音才肯安定。属七和弦里的导音上行半音解决到主音，那个半音是整个和声动力的来源——第 11 章讲属七和弦时已经说过，这里从变化音的角度再确认一次：半音远不只是装饰，它是推着音乐往前走的力。

第三层是戏剧性。连续的半音上行让人绷紧，常配恐怖、追赶、不祥的场面；半音下行则与叹息、哭泣、告别相连。这种对应不是物理定律，而是长期积累的听觉约定——往上走像用力，往下落像松劲，身体自然会这么理解。作曲家利用它，听众也懂它，双方共享一套不用说明的默契。

变化音之所以能承载表情，还因为它「不在预期里」。一段全是白键的旋律，听众心里已经建好了常态；一个升号打破它，注意力立刻被拉过去。表情来自偏离，而偏离要靠常态才成立——这和前面讲「变化音属于调式变音」并不矛盾：它属于这个调，但它是调里的客人，客人的出现本身就是事件。

> 边注｜同一串音写成等音异名，在钢琴上声音别无二致，在乐队里却可能改变演奏的表情。弦乐手看到升 F，心里想着「往 G 去」，运弓会带一点推进；看到降 G，想着「往 F 落」，语气马上不同。记谱从来不是中性的转录，它把演奏者对方向的理解提前写进了谱面。这也是为什么作曲家会为了一个音的写法反复斟酌。

## 八、从装饰到结构：浪漫主义为何离不开半音

把视线从单个音移到整段历史。在巴洛克与古典时期，变化音多是局部装饰：一个经过音、一个辅助音、一次短短的离调，很快回到自然音的轨道上。半音是「调料」，主菜仍是清楚的自然音调性。到了浪漫主义，半音的使用量激增，它从调料变成了语言本身——这部分在 M1 模块有详细叙述，这里只从乐理角度说明它靠什么做到。

和弦层面的变化最明显。那不勒斯六和弦建立在降低的第二级上，增六和弦含特征性的半音，它们都不满足于常规的属—主进行，而是把音乐带向更远的地方。这些和弦会在后面功能和声部分系统学习，此处先记住它们的音响效果：半音越多，「家」的位置越模糊，听众越难断定这段音乐究竟在哪个调上。调性依然在，但它的边界被半音泡软了。

常被提到的例子是瓦格纳《特里斯坦与伊索尔德》的开头：一个由半音冲突构成的和弦迟迟不解决，把「渴望」直接写进了和声语言——明明该回家，却一再把归途推迟。听这段时，主音久久不来，悬着的感觉几乎成了内容本身。李斯特、肖邦的钢琴作品里，半音音阶式的华彩段落则把半音同时用作炫技和抒情材料：它既是听得见的紧张，也是手指跑动的快感。

中国近现代音乐里同样有大量半音化处理，作曲家借它表现传统五声性旋律之外的色彩与张力。这说明半音化不是某一传统的专利，而是一种被普遍发现的表情资源：只要需要「不稳定、想往前、说不清」的效果，半音就是最直接的工具。理论上的总结与听觉上的直觉，在这里是同一件事。

> 听｜先听一段以自然音为主的民歌或进行曲，记下它的「明朗、确定」；再听肖邦《夜曲》中半音装饰密集的乐句，比较那份「说不清的」色彩。两者都只是音高与节奏的组合，差别很大程度上就在那些不在音阶上的音。有前面几节的准备，你甚至能指出它们多半是升四级、降七级或降六级。

## 九、半音音阶算不算一种独立的调式

> 分歧｜一种意见认为，半音音阶只是「调式变音积累到极端」的结果，它必须依附于某个具体的调才有意义——我们说升 F，总是相对于 C 大调的 F 而言，离开调，这个音的名字和去向都无从谈起。另一种意见（十九世纪后期以来的音高理论，以及二十世纪的十二音作曲实践）把十二个半音视为彼此平等的材料，半音音阶本身就是一种独立的音高组织，不再需要主音来统率。本章在入门阶段采用前一种口径，把半音音阶讲成「调内的极端变化」，因为它更贴近听众的听觉经验——人听音乐时仍在寻找一个家。后一种看法并非错误，它是理解二十世纪音乐的一把钥匙；把它追溯为「自古就有」的调式，则是一种事后的建构，而非史实。

两种口径在教学中各有位置。对刚学会自然大调的人，先告诉他「半音音阶是把调式变音用满」，他能立刻接上前面的知识；对准备接触现代音乐的人，则要说明「十二个音可以平等相处」，否则他无法理解为什么有的作品根本听不出主音。教学顺序本身就是一种取舍：先把半音讲成调内的偏离，再讲它可以脱离调而独立，比一上来就宣布「主音已死」更容易被听懂。

## 十、三个最容易混的地方

第一组：变化音与转调。变化音不改主音、不改调性，只改动其中一两个音；转调是主音搬家，整条音阶关系挂到新的中心上。判断标准是「家换了没有」：半音再多，只要还围着同一个主音，就仍是变化音。一段旋律听起来很「玄」，未必转了调——可能只是变化音用得多。

第二组：等音与同一个音。升 F 与降 G 在键盘上同键、在声音上同高，但在记谱上是两个音、在功能上指向两个方向。它们的关系是「同音异名」，不是「同一个音的两种叫法」那么简单：名字不同，意味着音乐要它做的事不同。

第三组：半音音阶与半音进行。前者是一整套音高材料，把十二个半音排成一列；后者是局部的旋律现象，相邻两音走半音。半音进行在任何调式里都能出现，并不需要整首作品都用半音音阶。把「用了半音」等同于「用了半音音阶」，是把材料与用法混为一谈。

三组区分可以压成一句口诀：记号管范围，变音管颜色，半音管距离。调号定底色，临时记号定本小节的改动；变化音在调内制造明暗与倾向；半音是十二个音里最短的距离，无论它被用来做装饰、做通道，还是铺成一整条音阶。

## 十一、本章要点

1. 变音记号写在音符前，升高或降低音高，含升、降、还原、重升、重降五种；它既改音高，也暗示音的去向。
2. 调号写在谱号后、管全曲，是整首作品的音高底色；临时变音记号只管所在小节，过小节线即失效。
3. 调式变音是在自然调式基础上把某级音升高或降低半音，主音与调性不变，与转调不同。
4. 升四级把第四级到第五级变成半音，生出导向属音的强推力；降七级把第七级到主音变成全音，削弱归家感、染上暗色。
5. 半音音阶由十二个半音排满一个八度构成，步步相等、没有重心，用作旋律材料、和声材料与转调通道。
6. 和声半音阶以大调为基础、在自然音的全音处插入半音，上下行同形，每个插入音都能在和弦中找到位置。
7. 旋律半音阶上行用升号、下行用降号、主音属音不变，靠音名给半音进行标出方向。
8. 变化音通过色彩、倾向、戏剧性三层功能改变表情；浪漫主义把它从局部装饰发展为结构与语言的核心。
9. 把半音音阶看作调内极端变化的口径更适合入门；把它当作十二音平等组织的看法，是理解二十世纪音乐的钥匙。

改一个音，能改变一句的表情；那么把整首曲子都往上搬、往下挪，又会发生什么？歌手唱不上去、小号手要换指法、作曲家想让同一段音乐出现在另一个高度——下一章讲移调，看音高怎样被整体搬运而关系保持不变。
