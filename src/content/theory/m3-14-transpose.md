排练厅里，小号手举起乐器，谱架上摆着一行没有升降号的 C 大调旋律。他按下第一个音，吹出来的却是降 B——比谱面上低了一个全音。指挥没有喊停，因为这本该如此：他手里那支是降 B 调小号，谱上写 C，乐器发降 B。旁边的钢琴手按下去的却是真正的 C。两份谱子摆在桌上看着差不多，音响却差了一个全音。这不是谁弹错了，而是记谱与发音之间被有意嵌入了一次整体的「搬运」。

类似的搬运每天都会发生。歌手唱到副歌的高音唱不上去，伴奏把它整体往下移两个半音；合唱团要适应女声的音域，同一首歌换个调重排；作曲家想让一段旋律在另一个高度重现，把它原样搬高八度。这些操作有一个共同点：每个音都按同样的距离移动，音与音之间的关系一点不变。本章就讲这次搬运是怎么想、怎么做、以及为什么有些乐器的谱子天生就要「错开」写。

## 一、歌手唱不上去时，到底改了什么

先从一个具体的麻烦说起。一位歌手拿到歌谱，主歌还行，副歌的最高音唱不上去。最常见的处理不是让他硬喊，而是把整首歌往下移两个半音——从 C 大调移到降 B 大调。伴奏的和弦、前奏的音型、间奏的过门，所有音一起往下挪同样距离。歌手再唱，指法与唱法都不用改，只是整体低了一些，声音舒服了。

这次操作改了什么、没改什么？改的是所有音的绝对高度：原来的 C 变成降 B，原来的 E 变成降 D。没改的是音与音之间的距离：原来 C 到 E 是大三度，移完以后降 B 到降 D 仍是大三度；原来两句之间的模进关系、和弦的功能走向、旋律的起伏轮廓，全都原样保留。换句话说，被搬走的是整栋房子，门窗家具一件没动——用术语说，是把一段音乐从一个[[key|调]]整体移到另一个调，而内部关系保持不变，这件事就叫移调。

注意「整体」二字。只把旋律挪高、和声留在原处，不叫移调，那会造成音响上的冲突。移调要求每个声部、每个音、包括调号与临时变音记号一起被处理，缺一不可。这也是为什么它看起来只是「把谱子往上挪」，做起来却要逐项核对——漏掉任何一个记号，搬过去的房子就会缺一堵墙。

落到听觉上，移调后的音乐「听起来还是同一首」：你依然认得那段旋律，跟着哼不会走音，情绪也没变。变的只是它占据的音区——亮一些还是暗一些、紧一些还是松一些。作曲家有时明明没有音域问题，也会选择移调，就是为了这份音区色彩：同一段旋律写在高音区更明亮，写在低音区更厚重。

把目的归一下类，移调无非出于三种需要。为嗓音：把作品移到歌手的舒适音区，这是最常见也最务实的一种，歌唱家常会根据当天状态临时决定移高或移低。为乐器：让作品适配某件乐器的音域与指法——把一段为小提琴写的旋律移到中提琴上，或让管乐声部避开低音区的含混，都要靠移调。为色彩：同一段音乐移到不同音区，明暗与张力随之改变，作曲家用它制造对比，而不解决任何实际困难。三种目的对应同一种操作，区别只在为什么动手。

## 二、移调与转调：一个换地址，一个换家具

上一章讲的是转调，极易与本章的移调混。两者都涉及调的改变，但操作对象完全不同。转调发生在音乐进行的中途：曲子本来在 C 大调，弹着弹着转到 G 大调去了，主音换了、调性中心换了，这是一次「进行中的事件」。移调则是把整首作品或整段音乐搬个位置：从头到尾都在新调上，原本的调性中心整体平移，中途并没有「换调」的动作。

打个比方。转调像一户人家住到一半搬去了另一个城市——生活地点变了，故事在途中转折；移调像把整栋房子连同地基一起平移到另一块地上——内部结构纹丝不动，只是地址改了。听众的感受也不同：转调能听见「转折」，因为有个从旧调到新调的过程；移调听不见转折，因为音乐从第一音起就已经在新调上，没有对比的参照。

术语上还有一层麻烦需要提醒。中文乐理教材里，「移调」与「转调」分得清楚，但在英文语境里，与「移调」对应的词有时也被用来指别的事情，不同教材的对应方式并不统一。本章按国内通用口径：整首搬动称移调，中途换调性中心称转调。读者若翻到说法不同的书，先看清它指的是「整体搬动」还是「中途换调」，就不会被名字绕住。

> 边注｜一个常被问到的问题：把一段旋律上移八度，算移调吗？按本章口径算——它是移调的一种特例，叫八度移调。八度移调有个特点：音名不变、只在谱表上换个八度位置，调号也不用改，因此是最容易操作的一种。短笛、低音提琴等乐器记谱与实际发音相差的正是八度，后面会讲到。

## 三、按音程移调：给每个音数格子

第一种基本方法叫按音程移调：先确定要搬多远、往哪边搬，再把每个音按这个音程移到新位置。比如把一段 C 大调旋律整体移高大二度，操作就是每个音都往上数一个大二度，然后把调号也改成新调的——原调是 C 大调（无升降号），上移大二度后成为 D 大调（两个升号，升 F 与升 C）。

具体看几个音。C 移高大二度是 D；E 移高大二度是升 F；G 移高大二度是 A。原来旋律里的 C—E—G，移完变成 D—升 F—A，正好是 D 大调的主和弦，音程关系一丝不差。注意 E 移上去要写成升 F，不能写成降 G——虽然它们在键盘上同键，但 D 大调的音阶里需要的是升 F，写成降 G 会让读谱的人摸不着头脑。等音的知识在这里派上了用场：音高相同，写法要服从新调。

变音记号也必须一起搬。假设原旋律里有一个升 F（C 大调的升四级），整体移高大二度后它应该变成升 G——因为升 F 到 G 是半音，保持相同音程关系，上移大二度就落在升 G 上。只搬音的位置、忘搬变音记号，是初学者最常犯的错。还有还原号：它取消了原本该升或该降的音，移到新调后要判断新调号是否仍会改变这个音，再决定写不写还原号。

检验一次移调对不对，有个简单办法：在原谱和新谱上各挑相邻两音，数一数它们的度数与半音数——若两处一致，这段就没搬错。再挑一个跨小节的音型看它的重复关系是否保留。音程关系是移调的「指纹」，指纹对上了，音高搬多远都不会认错曲子。

按音程移调的优点是可核对：每个音都能拿音程尺子量一遍，对不对一目了然。它尤其适合短小的片段、或者只需要移到某个特定高度的情形。缺点是要逐个音处理，段落一长就很费工夫，而且每次都要重新判断变音记号的去向，容易累中出错。

## 四、按调号移调：换一副滤色镜

第二种方法叫按调号移调，思路完全不同：不去逐个数音程，而是先认出每个音在原来调里的「身份」（是第几级音），再换上新调的调号，把这个身份原样安放到新调对应的音上。原调的 do 到新调还是 do，原调的四级音到新调还是四级音——身份不变，整体音高自然跟着新调移动。

举例说明。C 大调里一段 do—mi—sol，音是 C—E—G。要把它移到 D 大调，先写出 D 大调的调号（两个升号），再按同样的身份找出新调里的 do、mi、sol：D 大调的 do 是 D，mi 是升 F，sol 是 A，于是写成 D—升 F—A。结果与按音程移调完全一致，但思考方式不同——前者数距离，后者认身份。

这个方法为什么快？因为级数关系自动保留了。原旋律里若有两个音构成大三度，它们的身份是「一级到三级」；在新调里，一级到三级天然还是大三度，不必重新计算。这副「滤色镜」换上去，整段音乐的调内关系原封不动地透过来。原调里的升四级到了新调仍然是升四级——你只要知道新调的四级音是哪个、再把它升高半音即可。

> 边注｜按调号移调的前提，是你真的认得新调的音阶。熟练的人看到 D 大调的两个升号，能立刻说出 D、E、升 F、G、A、B、升 C 这一串；不熟的人一个个现数，反而比按音程移调还慢。所以两种方法的取舍，取决于你对目标调的熟悉程度：目标调烂熟时用调号法快，目标调陌生时用音程法稳。

它也有短板。换调号不只是把升号降号抄一遍：原调里的临时变音记号仍要按新调的身份重新判断——原调的升四级在新调里未必还是升四级加升号的形式，得看新调本身有没有改那个音。此外，若旋律经过离调或有复杂的临时记号，按身份对应会比按音程数复杂。实务中两种方法可以混用：先按调号定大框架，再对有疑问的个别音按音程复核。

## 五、两种方法什么时候用哪个

面对一段要搬的音乐，先别急着动手，问自己三个问题：搬多远、目标调熟不熟、片段长不长。搬多远决定工作量——只需移高八度的话，连调号都不用改，直接换八度写即可；移高大二度、小三度这类，就得完整处理调号与变音记号。目标调熟不熟决定方法——熟调用按调号移调快，生调用按音程移调稳。片段长不长决定要不要分块——长段落最好先划出乐句，逐句搬、逐句核，避免一口气写完才发现错在开头。

给一个可操作的流程：第一步，在原谱上标出调号与所有临时变音记号；第二步，确定目标调，写出新调号；第三步，选方法——逐音按音程搬，或按级数身份对应；第四步，逐个处理变音记号，特别留意还原号；第五步，通唱一遍，用耳朵检查音程关系有没有走样。第五步最容易被省略，却最能救回前四步的疏忽——旋律一旦唱顺，问题往往自己浮出来。

两种方法在实务里的分工大致如此：临时移调、移一两个音、或者为某件乐器翻谱，按音程更直接；整首歌换调、改编曲、为不同声部批量重排，按调号更有条理。熟练的乐手常常在心里把两者合成一套动作——既数距离，也认身份，互相验证。

| 比较项 | 按音程移调 | 按调号移调 |
|---|---|---|
| 核心思路 | 每个音按固定音程数到新位置 | 认出音的级数身份，安放到新调对应音上 |
| 依赖什么 | 音程计算能力 | 对新调音阶与调号的熟悉度 |
| 变音记号处理 | 随音一起按音程搬 | 按新调身份重新判断 |
| 适合场景 | 短片段、临时移调、生僻目标调 | 长段落、整首换调、熟悉的目标调 |
| 主要风险 | 漏搬变音记号 | 认错级数或写错新调音阶 |

## 六、移调乐器：为什么谱上的 C 不是真的 C

现在回到开篇那支小号。它属于移调乐器——记谱的音高与实际发出的音高不一致的乐器。降 B 调小号谱上写 C，实际发降 B，比记谱低大二度；A 调单簧管谱上写 C，实际发 A，比记谱低小三度；F 调圆号谱上写 C，实际发 F，比记谱低纯五度。乐手按谱面演奏，指挥听到的却是另一个高度——记谱与音响之间隔着一道固定的音程。

为什么会这样？根子在乐器的构造史。早期的号类乐器没有活塞或键阀，只能靠嘴唇振动吹出泛音列里的音，要改变可调的音高就得换一根不同长度的管子（或换一套接管）。不同长度的管对应不同的「基调」，例如降 B 调的管发降 B，A 调的管发 A。演奏者记忆的指法与口型是按「这首曲子的 do」来组织的：在降 B 调小号上，他吹的 do 实际是降 B。为了让他拿到任何调的谱子都能用同一套指法，作曲家就按这件乐器的基调把谱子「反着写」——想听到 C，就写 D（因为降 B 调乐器写 D 发 C）。

这套看似别扭的规矩，好处是实实在在的：同一套指法在不同调的乐器上产生相同的唱名，乐手换乐器时不用重新学指法，乐队里不同调的乐器也能用「按唱名写」的谱子合在一起。代价则是记谱与实音分离，读总谱时必须把每件乐器的移调量算进去——这也是指挥和作曲家的基本功之一。

还有一种「八度移调」的乐器，音名不变、只差八度：短笛的实际发音比记谱高八度，低音提琴比记谱低八度。它们不改变调号，只改变音区。读谱时别把它们和降 B、A 调那类「改变音名」的移调乐器混为一谈——前者只要挪八度，后者要连调号一起换算。

## 七、常见移调乐器对照

下面这张表把常见移调乐器按「记谱音与实际音」的关系列在一起。表中「写 C 发什么」一栏，是判断移调量与方向的最快办法；「实际比记谱」一栏则直接给出换算结果。

| 乐器 | 写 C 实际发 | 实际比记谱 | 调号如何换算 |
|---|---|---|---|
| 降 B 调小号 | 降 B | 低大二度 | 记谱调减一个降号方向推算 |
| 降 B 调单簧管 | 降 B | 低大二度 | 同上 |
| A 调单簧管 | A | 低小三度 | 记谱调低小三度得实音调 |
| F 调圆号 | F | 低纯五度 | 记谱调低纯五度得实音调 |
| 降 E 调中音萨克斯 | 降 E | 低大六度 | 记谱调低大六度得实音调 |
| 降 B 调次中音萨克斯 | 降 B | 低大二度 | 与降 B 调小号同理 |
| 短笛 | 高八度的 C | 高八度 | 调号不变，只移高八度 |
| 低音提琴 | 低八度的 C | 低八度 | 调号不变，只移低八度 |

使用这张表要注意两点。第一，「实际比记谱低多少」和「写谱时要高多少」是相反方向的同一件事：给降 B 调小号写谱，若想让它发出 C 大调的音响，就必须在谱上写 D 大调——把目标调提高大二度记谱。第二，八度移调乐器虽然在表里单列，但它们只改音区、不改调号，换算时千万不要把它们的调号也跟着上下挪。

> 听｜找一段有降 B 调单簧管或圆号的管弦乐片段（许多古典交响曲的木管声部都很容易听到单簧管），一边看总谱一边听：谱上写着的音与你耳朵听到的音差了多少？先按表推算，再用耳朵核对。也可以让钢琴按谱面原样弹一遍单簧管的声部，比较两者的音高差——这是把移调从概念变成直觉的最短路径。

## 八、读谱技巧：移调乐手怎样一眼读出实际音

对移调乐手而言，读谱不是把音符「读成那个音」，而是读成「这件乐器会发出的那个音」。以降 B 调小号为例：见到谱上写 G，手指按 G 的指法，嘴里听到的是实际音高 F。熟练的乐手不会每次现算，而是把「记谱音」与「实际音」当成两个并行的标签同时挂着——谱面是 G，耳朵是 F，两者在脑子里一一对应。

换算调号有个省力办法：先确定记谱调，再按乐器的移调量推出实音调。降 B 调小号谱上若无升降号（记谱 C 大调），实际音响就是降 B 大调（一个降号）；若谱上是一个升号的 G 大调，实际音响是 F 大调（一个降号）——因为 G 往下大二度正是 F。A 调单簧管谱上无升降号（记谱 C 大调），实际音响是 A 大调（三个升号）。把「写 C 发什么」这条规则与调号的升降顺序合起来用，任何调都能推出来。

给作曲家和编曲者的反向技巧是「先把目标调提高，再写谱」。想让降 B 调小号发出实际的 D 大调，就写 E 大调；想让 A 调单簧管发出实际的 C 大调，就写 D 大调。规则只有一句：写谱时朝相反方向移——乐器实际比记谱低多少，你写的时候就比想要的实音高多少。把这句话记牢，就能避免最常见的方向搞反。

读总谱时还有一条经验：先看调号，再看这件乐器的名称，最后才看音符。因为调号决定「基准」，乐器名称决定「偏移量」，音符只是落在这个坐标系里的点。很多人在总谱里被移调乐器绕晕，根源是跳过了乐器名称直接认音符——那等于还没查汇率就算账。

这里还牵出唱名法的差异。固定唱名法的学习者把谱上的线间位置直接读成 C、D、E，遇到移调乐器必须再换算一次；首调唱名法的学习者把旋律读成 do、re、mi，移调乐器恰好维持唱名不变，读起来反而更自然——这也是许多管乐手习惯用首调思维的原因。两种方法各有训练价值，面对移调谱时，首调在「唱名即指法」这件事上占便宜，固定调在「音名即音高」这件事上更精确。知道自己在用哪一套，就能预判会在哪里出错。

## 九、移调乐器的记谱该不该保留

> 分歧｜关于移调乐器是否应改用「实音记谱」（即谱上写什么就发什么），长期存在两种意见。支持改革者认为：实音记谱更直观，指挥、作曲家与初次接触总谱的人不必再逐件乐器换算，也能减少写谱方向搞反的错误；既然现代乐器制造早已不受自然泛音列的限制，延续旧规矩只是历史惯性。反对者则指出：移调记谱让乐手在所有调的同类乐器上共用同一套指法与唱名，换乐器成本极低，改成实音记谱会迫使乐手重新学习每件的指法体系，代价远大于读谱上的便利。本章倾向于保留现行制度，但要承认它的门槛是真实的——这更像是一项在「乐手换器的自由」与「读谱者的便利」之间做出的历史取舍，而非单纯的对错问题。

这个分歧也解释了为什么教材口径不统一：有的把移调乐器放在「记谱法」里讲，强调它是一套书写约定；有的放在「乐器法」里讲，强调它来自构造与指法。两者说的是同一件事的两面——记谱约定之所以存在，是因为它服务于演奏上的便利；理解任何一面的读者，只要补上另一面，就能读懂对方的说法。

## 十、实务中最容易出错的几处

第一处，只改调号不改音符。把 C 大调的谱子换成 G 大调调号就以为完成了移调，结果只有 F 变成了升 F，其余音原地不动——这不是移调，是把一个音改了颜色。记住「改调号」必须配合「按级数重写音符」，缺一不可。

第二处，漏搬临时变音记号。原谱里某个升号或还原号，搬到新调后要么仍需要、要么不再需要、要么换成了另一种记号——它必须被逐个重新判断，不能留在原处假装没事。段落越长、离调越多，这一处越危险。

第三处，给移调乐器写谱时把方向搞反。乐器实际比记谱低，写谱就要比想要的实音高——这个反向关系极易记反，写下后务必用「写 C 发什么」那条规则回验一遍：若我写的这个音按乐器的规则发出来，是否正好是想要的调？

第四处，忘了八度移调乐器。短笛高八度、低音提琴低八度，它们不改调号，但若把它们当成普通乐器照谱记音区，写出来的声部会高八度或低八度——在总谱上听起来像少了件乐器。

第五处，目标调选择不当。移高小二度时，目标调既可以写成升 C 大调（七个升号），也可以写成降 D 大调（五个降号）——音高相同、调号繁简差别很大，择其简者写，是减轻演奏者负担的基本体贴。

## 十一、本章要点

1. 移调是把整首或整段音乐整体搬高或搬低，所有音移动相同距离，音程关系与旋律轮廓不变，只改变音区。
2. 移调是整首搬动、没有中途转折；转调是音乐进行中换调性中心、能听见转折，二者不可混。
3. 按音程移调是逐音按固定音程数到新位置，变音记号须随音一起搬，可逐步核对但费工。
4. 按调号移调是认出音的级数身份，换上新调号后安放到对应音上，依赖对新调音阶的熟悉。
5. 按音程适合短片段与生僻目标调，按调号适合长段落与熟悉目标调；实务中可先用调号定框架、再用音程复核。
6. 移调乐器的记谱音与实际发音不一致：降 B 调低大二度、A 调低小三度、F 调低纯五度，源于乐器构造与指法统一的历史。
7. 给移调乐器写谱要朝相反方向移：乐器实际比记谱低多少，写谱就比想要的实音高多少。
8. 短笛高八度、低音提琴低八度属八度移调，只改音区不改调号。
9. 移调最易错在漏搬临时记号、只改调号不改音符、方向搞反与忽略八度，写完后通唱一遍最能有效自查。

整体搬动音高，是把已有的旋律换个位置。可旋律本身为什么有的顺口、有的拗口，有的听一遍就记住、有的转瞬即忘？下一章从一条起伏的线条开始，讲旋律怎样组织音高与节奏，又怎样安排高潮与呼吸——基础乐理部分将在这里收束。
