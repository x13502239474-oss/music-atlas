排练厅里，合唱队唱完最后一句，指挥没让散。他指着谱子说：最后这个和弦再落一次，要唱到「家里」。队员又唱了一遍，这次尾音稳稳停在主音上，屋里的人不约而同松了口气。指挥又让人把结尾换成另一个和弦试了试——同样一段歌，同样的人物，那种「讲完了」的感觉忽然就不见了。

这口气松在哪里？不是作曲家写了个好看的终止记号，而是音与音之间有一种真实的重力：有的音让人悬着，有的音让人落地。本章把这种重力拆开，讲清主音为什么是家、属音为什么往外拽、调式色彩怎样叠在调性之上，以及为什么同一份调号能听出两种完全不同的性格。

## 一、为什么停在「do」上才像结束

[[tonic|主音]]是调式的中心音，其他音围绕它组织。判断一段音乐有没有结束，最直接的标志就是它有没有回到主音。但这只是描述，不是解释：为什么主音有这个特权？

第一个理由是泛音列。一个低音 C 发声时，它并不只发出一个频率，还同时发出一系列更弱的泛音，其中最靠前的几个依次是 C、G、C、E、G。也就是说，C、E、G 这三个音在物理上本来就「挤在同一个音里」。当乐手同时弹出 C、E、G 时，三个音的波形大部分重合，听感格外融合、稳定。主和弦的安定感有相当一部分来自这里——这不是比喻，是可以拿频谱看出来的事实。

第二个理由是习惯。音乐里反复用主和弦收尾，听者听了几百次，听到它就预期「要结束了」。这一层是文化养成，不是物理定律。把两层合起来看：泛音列让主和弦天然适合当终点，长期的音乐实践把这个适合固定成了惯例。两者互相加强，才有了今天这种「一听到就松口气」的反应。

> 听｜在钢琴上弹一小段 C 大调的音阶，故意停在 G 上，别往下弹，让这个音悬两秒；然后再弹一遍，这次停在 C 上。同一段旋律，只换了最后一个音，前一次让人想继续听，后一次让人觉得可以收工。接着按住 C-E-G 三个音不放，听听这个和弦有多「稳」——这就是主音的引力在耳边的样子。

要注意，主音不是「最好听的音」，而是「最适合当终点的音」。把一段旋律里每个音单独拎出来弹，C 未必比 E 动听；可一旦放进调性的关系网里，C 就成了重心。这个区别很重要：调性是一种关系结构，不是一份好听音的名单。离开关系谈某个音的地位，就像离开棋局谈某个棋子的价值。

这个比喻还能再推一层：同一枚棋子在不同局面里价值不同，同一个音在不同调里地位也不同。在 C 大调里，B 是第七级导音，强烈指向 C；到了 G 大调，导音换成 F#，它指向 G。同一个音级位置，换个调就换了一个音——谈音级之前必须先把调定下来，否则连「第七级是谁」都会说错。同样，主音的吸引力也不是它单方面拥有的，而是周围的属音、下属音与导音把它推到中心位置的结果；一个音若没有这些关系的衬托，单独响起来就只是一个音，谈不上稳定感。

## 二、音级为什么分「稳定」和「不稳定」

把 C 大调的七个音按「想不想继续走」排个队，就能得到一张稳定性表。最稳的是主音 C，它是家；次稳的是属音 G，它是家门外最有分量的一个音，既稳定又倾向于动；再次是三度 E 与五度以下的三级、六级；最不稳的是导音 B，它离 C 只有半音，几乎必须往上解决。第四级 F 也有向下走到 E 的倾向，但不如导音迫切。

| 音级 | 音名（C 大调） | 与主音的关系 | 稳定性 | 典型倾向 |
|---|---|---|---|---|
| 第一级 | C | 主音 | 最稳定 | 可作终点，不要求继续 |
| 第二级 | D | 大二度 | 不稳定 | 多向上或向下级进 |
| 第三级 | E | 大三度 | 次稳定 | 常下行到 D 或留在原地 |
| 第四级 | F | 纯四度 | 不稳定 | 倾向下行到 E |
| 第五级 | G | 纯五度（属音） | 次稳定 | 倾向上行到 A 或回到 C |
| 第六级 | A | 大六度 | 不稳定 | 常下行到 G |
| 第七级 | B | 大七度（导音） | 最不稳定 | 强烈上行半音到 C |

读这张表要抓住两个极点：主音 C 与导音 B。一个几乎不动，一个几乎必须动。音乐里的许多紧张与松弛，就是在这两个极点之间来回——离开家制造张力，回到家释放张力。中间那几个音是路上的风景，它们让这段往返不至于只有两个音。

> 边注｜这张表里的排序，一部分有声学依据（C 与 G 在泛音列里靠前，所以稳定；B 到 C 是半音，所以倾向强），一部分来自功能和声的长期实践（属七和弦必须解决，第四级倾向下行）。还有一部分是教学上的归纳，方便入门者记忆。本章把「主音最稳、导音最不稳」当作可靠的判断，把中间几级的精确排序当作参考而不是定律——这一点在 verify 里也标了出来。

稳定性不是每个音的固定属性，它随调式而变。同一个 B，在 C 大调里是导音，最不稳定；在 G 大调里它是第七级，虽然也倾向回到 C，但那个 C 已经不是主音了，它的身份和张力都变了。脱离具体的调谈「B 稳不稳定」，是没有意义的。这也是本章反复强调的一点：调性是一种关系网，离开网络，单音没有性格。

要把这张表用起来，可以做一个简单的观察：弹一段 C 大调的音阶，弹到 B 时停住，问自己想不想继续；再弹到 C 时停住，问自己是不是可以结束。多数人会觉得停在 B 上难受、停在 C 上自然。这种反应不需要学过和声，它是半音倾向在日常听觉里的直接体现。初学者若对「稳定」这个词感到抽象，就从这两个音开始体会——B 想走，C 不想走，稳定性说到底就是这两种倾向的差别。

## 三、属音为什么有「往下拽」的重力

属音是主音上方纯五度的那个音，在 C 大调里是 G。它与主音的关系极近——纯五度是泛音列里第二个出现的音，频率比简单，两个音同时响时非常融合。但属音不是单纯的「次主音」，它有一种向外拉扯的力量，这种力量在[[dominant-seventh|属七和弦]]上表现得最清楚。

属七和弦建立在属音上，以 C 大调为例，它是 G-B-D-F：在 G 上叠一个大三度 B、一个纯五度 D，再加一个七度 F。关键在于 B 和 F 这两个音，它们之间隔了六个半音，构成一个三全音。三全音是不协和的，两个音同时响时听起来「互相顶着」，有一种非要分开不可的压力。解决的办法是：B 往上走半音到 C，F 往下走半音到 E——两个音各退一步，三全音消失，落到 C-E-G 这个安稳的主和弦上。G 到 C、B 到 C、F 到 E，这一系列运动合在一起，就产生了前面那种「落定」的感觉。

> 听｜在钢琴上先单独弹 G-B-D-F 四个音，按住三秒别松，体会那种悬着的不适；然后让 B 升到 C、F 降到 E，其余两个音保持或并入主和弦，弹成 C-E-G。前后两个和弦只动了两个音，可后一个一下子就「落地」了。这个实验把属七和弦的重力放到了最小单位：两个音、各半音、一次解决。

属七和弦的「必须解决」不是硬性规定，而是一种强烈的听觉期待。作曲家常故意拖着不解决，让听众悬在那里；也可能解决得晚一点、绕个弯，制造意外。但无论怎样变通，那个期待始终是参照系——正因为听众知道「应该回主和弦」， delaying 才有张力。本章只讲最基本的形态，属七和弦在其他和声位置上的用法留给 m3-11。

把属音与主音的关系推广一点，就得到调性里最重要的两条力：主音吸引，属音推离。一条往回拉，一条往外推，作品就在这两股力之间展开。理解这两条力，比背下几十条和声规则更有用——因为规则会变，这两股力在近三百年的音乐里几乎一直起作用。

把这条原则用到聆听上，也能形成一个简单的习惯：听到一个和弦，先别急着说它好不好听，问问它想往哪里去。属七和弦想回主和弦，导音想上行到主音，这类「想去哪里」的判断，比单纯的情绪词更能说明音乐在做什么。听多了你会发现，多数调性音乐都在重复同一条路线——离家、徘徊、回家——不同的只是路程长短与绕的弯子。

## 四、调式色彩怎样叠在调性上

到这里可以给「调」和「调式」一个分工。[[key|调]]决定「哪个音是家」，也就是主音的音高位置；[[mode|调式]]决定「回家的路是什么样」，也就是音阶内部的距离关系。两者叠加，才得到一段具体的音乐。上一章讲调式时只看音程结构，本章把它放回调性里，看看两者怎样合作。

最直观的对照是同主音的大小调。C 大调与 c 小调都以 C 为主音——家在同一个地方，路却不同：C 大调的第三音是 E（离主音四个半音），第六音是 A，第七音是 B；c 小调的第三音是 Eb（三个半音），第六音是 Ab，第七音是 Bb（若用和声小调则升为 B）。第三、六、七级三个音全都降了半音，明亮的路变成了柔和的路。

| 音级 | C 大调 | c 小调 | 相差 |
|---|---|---|---|
| 第一级 | C | C | 相同 |
| 第二级 | D | D | 相同 |
| 第三级 | E | Eb | 降半音 |
| 第四级 | F | F | 相同 |
| 第五级 | G | G | 相同 |
| 第六级 | A | Ab | 降半音 |
| 第七级 | B | Bb | 降半音 |
| 第八级 | C | C | 相同 |

八个音里只有三个不同，听感却相差很远。这三个音恰好是上一章说的关键位置：第三音决定明暗，第七音决定牵引，第六音影响色彩。调性没有变（家还是 C），调式变了（路变了），音乐就换了一副表情。这就是「调式色彩叠加在调性上」的字面意思。

> 边注｜同主音大小调常被拿来和「关系调」比较，两者正好互补：同主音调是家相同、路不同；关系调是路相同（同一组音）、家不同。C 大调与 c 小调属于前者，C 大调与 a 小调属于后者。把这两组词摆在一起记，上一章与本章的调关系就接上了。

反过来也成立：同一段音阶，换一个主音，调式色彩也会变。C 大调音阶的七个白键，若把 A 当主音，就成了 a 小调的自然形式——音没换，路没换，家换了，颜色照样不同。这说明「调」与「调式」虽然能分开讲，在实际音乐里却总是绑在一起出现，听者接收到的永远是二者叠加后的整体效果。

把这两层分开说还有一个实用好处：读谱时知道该看哪里。想知道一首曲子的音高位置、适合什么音域，看调号与主音；想知道它为什么明亮或柔和，看调式里的第三、六、七级。两件事可以分别判断，最后再合起来理解。很多人学乐理时把「调」和「调式」搅成一团，是因为教材常把它们连写成「调式调性」一个词；其实拆开看，每一步都简单，合起来才复杂。这也是为什么同一首歌用大调和小调各写一遍，旋律骨架可以不变，情绪却全然不同——变的只是那几个关键音级。

## 五、同一个调号，为什么能听出两种调式

上一章留了一个尾巴：两个升号的谱子，既可能是 D 大调，也可能是 b 小调。现在可以完整回答。两个升号意味着 F# 和 C# 已进入音阶，可用的音是 D、E、F#、G、A、B、C# 这七个。若以 D 为主音，第三音 F# 离主音四个半音，是大调；若以 B 为主音，第三音 D 离主音三个半音，是小调。同一组音，因为选的主音不同，音阶结构就不同——这正是上一章「同样七个白键、两种颜色」在带调号情形下的翻版。

在钢琴上验证只需两个和弦。弹 D-F#-A，再弹 B-D-F#。前者三个音叠出的是一个明亮的大三和弦，后者叠出的是一个柔和的小三和弦。两个和弦用的音全都来自那七个音，调号也完全相同；区别只在以哪个音为底。听者判断调式，靠的不是数谱号后面的升号，而是听哪一串音被反复强调、最后落在哪里。

这里要防止一种想当然：以为「两个升号就是 D 大调」。调号给的是一组音，不是一份判决书。作曲家写两个升号，是因为这组音用起来最省记号，不是因为宣布了 D 是主音。真正的判断要交给音乐本身——落音、和弦的重心、反复出现的音，这些才是主音留下的指纹。

把这句话再推一步：谱面与听觉的这层错位，在流行歌曲里尤其常见。一首歌为了照顾歌手的音域，整体升高两个半音来唱，谱子若仍按原调印，听众听到的主音就和调号对不上。乐队伴奏跟着歌手走，实际音乐的调早已改变，印在谱面上的调号却原地不动。这不是谁写错了，而是记谱、演唱与聆听分属三个环节，各自有各自省事的方式。读者遇到这类情况，记住一条即可：耳朵永远比标签更接近正在发生的音乐。把这句话收进本章：调号是谱面的语法，主音是听觉的重心，学乐理就是要学会在两者之间来回核对。

## 六、怎么判断一段旋律是大调还是小调

把前面各节收拢成一套可操作的办法，零起点的读者也能用。第一步，听结尾。乐句或全曲最后的长音常常是主音，先把它定下来。第二步，找第三音。从这个候选主音往上数三个或四个半音，看旋律里出现的是哪一个：三个半音偏小调，四个半音偏大调。第三步，找第七音。如果第七音被升高成导音、与主音差半音，那是和声小调的标记；如果第三音是大三度而第七音离主音两个半音，可能是多利亚或混合利底亚。

举个具体的例子。一段两个升号的旋律，结尾落在 B 上，反复出现 A#。按第一步，主音是 B；按第二步，往上数三个半音是 D，这个音也在旋律里反复出现，是小三度；按第三步，A# 正是第七音 A 升高半音后的导音，与 B 只差半音。三条线索一致，可以判断为 b 和声小调。这里提醒一句：数半音最好用琴键逐一核对——B 到 D 是三个半音，A 到 B 是两个半音，升成 A# 后才是一个半音。凭印象数容易出错，尤其当旋律里同时出现 D 与自然 D 的相邻音时更要看清。

> 边注｜这套办法给出的是「最可能的判断」，不是唯一答案。有的旋律刻意模糊调式，开头像大调、结尾像小调；有的五声旋律根本没有导音可找，第三音也可能时而大时而小。遇到这种情况，承认「听不准」比硬套一个名称诚实。判断调式是听感的归纳，不是做算术题——工具能提高把握，不能替代耳朵。

判断调式还有一条捷径：看和弦。一段旋律若总在 D-F#-A 上停留，大调的嫌疑很大；若总在 B-D-F# 上停留，小调的嫌疑很大。和弦比单音携带更多信息，因为它同时告诉你主音和第三音的距离。把「听结尾音」和「看和弦的三度」两条合用，多数旋律都能定下来。

## 七、转调和换调式，不是一回事

初学者常把「转调」和「换调式」说成同一件事，其实两者的动作方向不同。转调是主音换了家：从 C 大调转到 G 大调，主音从 C 搬到 G，音阶整体移高。换调式是主音不变、路变了：从 C 大调变成 c 小调，家还在 C，但第三、六、七级降了半音。一个搬了家，一个没搬家而重新装修了房子。

两种变化的听感也不同。转调带来「移动感」——熟悉的关系还在，只是整体挪了位置，像把一首歌换了调门唱。换调式带来「变色感」——位置没动，气氛却从晴朗转成阴柔。电影配乐里常利用这一点：表现时间流逝或场景迁移，用转调；表现同一场景里的情绪翻转，用同主音的大小调切换。两种手段对应两种戏剧目的。

从记号上看，换调式通常意味着调号改变（C 大调的零个升降号变成 c 小调的三个降号），而转调也常改调号。只看调号变化，分不清是哪一种；必须看主音有没有动。主音动了是转调，主音没动是换调式。转调的具体做法、近关系转调的路线，留到 m3-12 展开；本章只负责把两者的区别讲清，免得后面的学习被这两个词绕住。

还有一种中间情形值得提一句：有的曲子主音没变，调号也没变，却在大调与小调之间来回——比如一段 C 大调的旋律逐渐强调 Eb 和 Ab，听感慢慢偏向 c 小调。这种情况叫调式的游移，处在「换调式」的过渡带上。它提醒我们，调与调式的边界在实际音乐里并不总是刀切般整齐，教材里的分类是为了讲清楚而做的简化。

同主音换调式在键盘上有个很直观的验证：把 C 大调音阶里的 E、A、B 三个白键，分别换成左边的黑键 Eb、Ab、Bb，其余白键一律不动。手指的动作很小，只挪三个键，整段音阶的表情却全变了。这个实验说明，调式色彩并不神秘，它有时就藏在三颗黑键里。反过来说，当一段音乐从明亮转为柔和时，值得留意是不是恰好有三个音降了半音——这往往是同主音调式切换留下的痕迹。

## 八、判断调式时，主音和调号哪个优先

方法讲完，剩下一个口径问题。同一段音乐，若谱面调号和听觉重心指向不同结论，该听谁的？两种教学传统给出的答案不一样。

> 分歧｜一种做法以调号和音阶集合为起点：先看用了哪些音、调号有几个升降，再据此判断调式；另一种做法以主音和落音为起点：先听哪里是家，再看这个音与周围音的关系。多数时候两条路得出相同结论；当调号与音乐重心分离——比如谱面写 C 大调，旋律却总停在 A 上——两者就会给出不同答案。本章倾向于后一种：先听主音。理由是调号属于书写系统，可以用最省记号的写法，而耳朵听到的重心才是音乐实际在做的事。但本章不把这种倾向说成唯一正确，另一条路在快速读谱和风格分析里同样有用。

把这条倾向用回前面讲过的那个例子：两个升号的谱，若音乐反复强调 B 并落在 B 上，本章就称它为 b 小调，尽管调号也能服务 D 大调。若换一位以调号为先的读者，他可能先把它记作 D 大调的「小调色彩段落」。两种描述指向同一段声音，差别在从哪一头切入。知道这一点，读到不同教材对同一段音乐给出不同调名时，就不会急着判定谁错了。

对零起点的读者，本章给一个稳妥的顺序：先用耳朵定主音，再用调号验证；两者冲突时，承认存在分歧，并把分歧本身记下来——这比强行选一个答案更接近音乐学习的真实状态。调式判断本来就是带判断力的听感归纳，不是查表填空。

这种分歧并不只发生在初学者之间。不同版本的乐谱、不同传统的教材，对同一段音乐可能给出不同的调名，背后往往是判断起点的不同：有人从记谱的方便出发，有人从听觉的重心出发。知道这一点，遇到调名不一致时先别急着找「标准答案」，不妨问一句：这个判断是从谱面做的，还是从耳朵做的？问清楚了，分歧常常就消解了——两个人说的本来就不是同一层面。

## 九、本章要点

1. 主音是调式的中心音，适合当终点；它的稳定感一半来自泛音列（C-E-G 天然融合），一半来自长期音乐实践养成的习惯。
2. 音级可按稳定性排队：主音最稳、导音最不稳，属音次之；中间几级的精确排序带教学归纳成分。
3. 属七和弦建立在属音上，含三全音，B 上行半音到 C、F 下行半音到 E，解决到主和弦，产生「落定」感。
4. 调决定主音的位置，调式决定音阶内部的距离；两者叠加才得到具体的听感。
5. 同主音大小调的家相同、路不同：C 大调与 c 小调只在第三、六、七级相差半音，听感却明显不同。
6. 同一调号可以对应两种调式：两个升号既服务 D 大调也服务 b 小调，区别在主音和和弦重心。
7. 判断调式可依次听结尾音、数第三音的距离、找第七音是否升高，并参考反复出现的和弦。
8. 转调是主音搬家，换调式是主音不变而音阶改变；前者带来移动感，后者带来变色感。
9. 当调号与听觉重心冲突时，本章主张先听主音，同时承认以调号为先的读谱传统也有其用途。

到这里，一组音怎样被选出来、怎样排成音阶、怎样围绕一个中心组织成有稳定与紧张的调性，已经讲完。可音乐并不总在同一个调里安分地走，它还会转调、会临时偏离、会把半音塞进原本纯净的音阶——下一章从调式中的音程讲起，看这些变化怎样发生。
