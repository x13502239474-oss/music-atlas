把一段熟悉的旋律在钢琴上弹两遍：第一遍用 C 大调，第二遍把每个音都提高纯五度、按 G 大调的调号弹。音与音之间的关系一点没变，听上去却是「同一首歌，换了件衣服」——第二遍整体亮了一些，落音也换了地方。这件衣服就是[[key|调]]。作曲家让音乐从一个调走到另一个调，并在新调里安顿下来，这件事叫[[transposition|转调]]。

上一章的离调是短暂借道，转调却是真的搬家。搬家要修路：两调之间得有一座桥，让和声走得过去、又站得住。本章就讲这座桥怎么搭——近关系调怎么选、共同和弦怎么当桥、模进怎样把乐思一边重复一边带走。读完后，读者应能看着谱回答：这里到底只是离调，还是真的转了调？

## 一、一段旋律搬家，究竟搬的是什么

先分清两件容易混的事。把整首曲子原封不动移到另一个调演奏，叫移调——音高整体平移，调性关系不变，属于「搬运」。而转调是作品进行到中途，从原调进入另一个调并继续发展，属于「改建」。前者是全曲换衣服，后者是房子住到一半搬到另一处。本章讲的是后者。

转调搬的「家当」有三样：主音、调号和调式色彩。主音从 C 变成 G，稳定感就围绕 G 组织；调号从没有升降号变成一个升号，F 音从此要弹成升 F；大调若转去关系小调，整段音乐还会由明转暗。三样里主音是核心——听众判断「到家了没有」，靠的是新的主和弦是否稳定落地，而不是看谱上写了几个升降号。

转调也不是随便换。它往往需要铺垫：先让新调的属和弦出现，把耳朵引过去，再用新调的主和弦收住。少了这个铺垫，听众会觉得「突然跑调了」，而不是「自然地到了新地方」。下面几节讲的桥与中介和弦，本质上都是为了让这个过渡听得顺。

在真实作品里，转调的位置也有讲究。它很少发生在乐句刚开头——那时新调还没站稳，听众也还没认出原调的主题。更常见的位置是乐句末尾或段落之间：前一句把话说完，后一句换个调接着说。这样转调既是休息，也是新段落的起点，听感上有「换口气」的余地。找一个有转调的经典段落听一听，多半会落在这样的接缝处。

> 边注｜「移调」与「转调」在英文里都和 transposition 有关，中文却分得很清：前者是整个作品平移，后者是作品内部的调性转换。术语表把 transposition 记为「转调」，本章沿用这个中文对应；读者若在别处看到 transposition 指移调，知道是同一个词在不同语境里的用法即可。

## 二、近关系调为什么「近」，用调号数一数

转调有近远之分。最直观的量法是数调号：两调的调号相差不超过一个升降号，叫近关系调；差得更多，就是远关系调。以 C 大调（零个升降号）为例，相差一个号以内的调共有五个，列成表便一目了然。

| 与 C 大调的关系 | 目标调 | 调号 | 两调共有的音 |
|---|---|---|---|
| 属调 | G 大调 | 一个升号（升 F） | 除 F 外六音相同 |
| 下属调 | F 大调 | 一个降号（降 B） | 除 B 外六音相同 |
| 关系小调 | a 小调 | 无升降号 | 七音完全相同 |
| 属调的关系小调 | e 小调 | 一个升号 | 除 F 外六音相同 |
| 下属调的关系小调 | d 小调 | 一个降号 | 除 B 外六音相同 |

这张表说明「近」的实质：两调共用六个甚至七个音，只有一两个音不同。因此从 C 转到 G，只需把 F 换成升 F，其余音照旧；转到 a 小调更省事，连调号都不改，只是把稳定中心从 C 挪到 A。共用的音越多，转调越平滑——这就是近关系调常被优先使用的原因。

反过来看远关系调，比如 C 大调转到升 F 大调（六个升号），两调几乎没几个音相同，硬接会很突兀。这类转调需要更特殊的桥梁，例如等音转调，那是下一章的主题。本章先把近关系这条「好走的路」讲透，再谈远关系就有参照。

为什么偏偏是「一个升降号」作界线？因为调号每多一个升降号，就多换掉一个音级。差一个号，只换一个音，两调仍有六个音共用；差两个号，就换掉两个音，共同音减少，桥就变窄。把各调按相差一个升降号的关系连起来，会得到一条环环相扣的链——音乐沿着这条链一格一格走，每一步都只换一个音，听起来最不费力。近关系调之所以「近」，本质上就是这条链上的邻居。

## 三、共同和弦怎样当桥，中介和弦的原理

既然两调共用大量音，就一定有共用[[chord|和弦]]。所谓共同和弦，指在两个调里都存在、且音高完全相同的那个和弦。它能同时被两边解释，于是成了转调的桥：在出发调里按原身份使用，到了某个时刻改按目标调的身份解释，音乐便自然滑了过去。

共同和弦并不神秘，任何一个由两调共有音组成的三和弦都可能充当它。从 C 到 G，两调共有 C、D、E、G、A、B 六个音，用这些音叠出的 C、Dm、Em、G、Am、Bdim 全都是共同和弦。数量看似不少，但真正好用的只是其中功能明确的那几个——这也是下一节要讲的「选择诀窍」。先知道「候选很多」，再学「怎么挑」，思路才不会乱。

以 C 大调转到 G 大调为例。C 大调的 I 是 C（C—E—G），这三个音在 G 大调里恰好构成 IV（G 大调音阶为 G—A—B—C—D—E—升 F，C—E—G 正是它的四级）。于是同一个 C 和弦，先在 C 大调里当「主」，随后被重新当成 G 大调的「下属」——它身兼两职，这就是中介和弦。听众听到的是「主和弦没有走远，却悄悄变成了新调的下属」。

另一种走法是用 G 和弦（G—B—D）：它在 C 大调里是 V，在 G 大调里是 I。这个和弦更妙，因为它本身就是两调主属关系的交汇点——从 C 看是属，从 G 看是家。用它作中介，转调几乎不需要额外的转折，只需在它之后接上 G 大调的属七与终止式，新调就立住了。

> 听｜在琴上弹 C—G—D7—G。先把它听成 C 大调：C 是主，G 是属，可 D7 里的升 F 不属于 C 大调——耳朵到这里会「拐一下」。接着把最后的 G 听成新家的主音，D7 就是 G 大调的属七，升 F 是它的导音。同一串和弦，前半在 C、后半在 G，那个升 F 就是转调的接口。

## 四、选中介和弦有什么诀窍

不是任何一个共同和弦都好用。挑中介和弦有两条经验。第一条：优先选在目标调里功能明确的和弦。比如转到 G 大调，用 C 作中介（在 G 里是 IV）或 G 作中介（在 G 里是 I）都很好，因为它们在目标调里有清楚的角色；若挑一个在目标调里功能模糊的和弦，转过去之后就不知该往哪走。

第二条：让中介和弦紧挨着目标调的属和弦。桥梁修好，还得接上引路的车。典型序列是「原调主 — 共同和弦 — 目标属七 — 目标主」。以 C 转 G 为例：C（原调主兼目标 IV）— D7（目标属七）— G（目标主）。三步走完，新调既被引入又被确认，听感干净利落。省掉中间的属七，直接从共同和弦跳到目标主，新调就站得不够稳。

还要顾及声部平顺。中介和弦之所以能当桥，除了功能上说得通，还因为两调共用的音不需要改动——F 在 C 调里是 F，到了 G 调要变成升 F，这个变化最好发生在某一条声部里半音上行，听起来像它自己「爬」上去的。若几个声部同时跳动，桥就会晃。

初学者常犯的错，是把「共同和弦」和「目标调的属和弦」混为一谈。前者是桥，负责把两调接起来；后者是引路的车，负责把音乐推向新主音。两者功能不同，位置也不同：桥在前，车在后。以 C 转 G 为例，C 是桥，D7 是车，G 是目的地。把顺序弄反，转调就会显得生硬。写和声题时不妨先在小纸上标出「桥—车—目的地」三格，再往里填和弦，出错率会低很多。

## 五、转到新调后还要落地：确认与终止式

转调的完整过程可以拆成五步：定目标、找共同和弦、给它派新角色、接目标调的属七、用目标调的终止式收住。前四步把她「引到门口」，第五步才真正「进门」。这里要强调第五步的分量：没有新调的终止式，中介和弦就只是经过，听众不会认为换了调。

终止式是什么？简单说，就是属和弦到主和弦的收束（V—I），像一句话的句号。在目标调里弹一次明确的 V7—I，等于宣布「新家在这里」。从 C 转 G 的例子里，D7—G 就是 G 大调的终止式；它一出现，G 才从「经过的属和弦」升级为「新的主音」。

判断一段音乐是否真的转了调，可以拿这五步当检查表：能否指出明确的目标调？是否有共同和弦作过渡？目标调的属七是否出现？是否有目标调的终止式？新调是否持续了足够长的时间（至少一两个乐句）？五项都满足，才叫转调；只满足前几项、很快又回到原调，那更可能是上一章的离调。

这张检查表也能反过来用：若想自己写一段转调，就照五步依次落实，缺哪步补哪步。很多人写出的转调「听着不对」，追根究底往往是漏了目标调的终止式——音乐滑到了新调，却没在那儿收口，于是像走到了门口又折返。补一个干净利落的 V7—I，问题通常立刻解决。这比凭感觉反复试要可靠得多。

> 边注｜调号在转调处的写法，各家不完全一致。有的作曲家在转调段落开头画新调号，有的只用临时升降号逐个标记，还有的在段落中间换调号。读谱时别只盯着谱首那一个调号，要看乐句内部是否出现了新的升降号体系——那才是调性真正移动的地方。

## 六、模进是把同一句话换个高度再说一遍

[[sequence|模进]]指把一个旋律片段或和声进行，整体移到另一个音高上重复一次或几次。它是作曲里最省力的「发展」手段：材料不用重新想，换个高度再说一遍，听众既认得出主题、又听到新东西。像把同一句话用不同的调门讲，内容没变，语气变了。

模进之所以有效，是因为它同时满足两种相反的需求。听众需要「认得出」——完全陌生的材料听不出联系，作品就散了；听众也需要「有变化」——一模一样的重复又太单调。模进恰好卡在中间：骨架是旧的，音高是新的。作曲家因此不必凭空发明新主题，只需把旧主题挪个位置，就得到既熟悉又新鲜的材料。这一点在篇幅较长的作品里尤其重要。

模进按音高移动分上行与下行，按严格程度分严格与自由。严格模进要求每个音程原样搬移——例如一个「上行大二度、下行小三度」的片段，移到新高度后仍是「上行大二度、下行小三度」；自由模进则允许为适应新调而改动个别音程。初学辨认时先听严格模进，因为它最容易在听觉上认出「同一句换了高度」。

模进还可以按范围分调内模进与转调模进。前者片段始终在本调音阶内游走，不改变调性；后者一次次往上或往下搬，搬着搬着就把音乐带进了新调。本节先建立「模进 = 移位重复」的概念，下一节专门看它怎样成为转调的工具。

| 模进类型 | 移动方向 | 音程是否严格保持 | 是否改变调性 |
|---|---|---|---|
| 调内严格模进 | 上行或下行 | 是 | 否 |
| 调内自由模进 | 上行或下行 | 否（为适应调式微调） | 否 |
| 转调模进 | 连续上行或下行 | 通常严格 | 是，逐步进入新调 |

## 七、模进怎样把调走过去

转调模进的妙处，在于它把「搬家」拆成许多小步。每次模进只移动一两个音级，听起来像重复；可连续几次之后，累计的距离足以跨到另一个调。听众在不知不觉中被带走了——这正是模进作为转调手段的价值。

举个例子。在 C 大调里弹一个短片段：C—D—E（三个音上行），随后原样移到 D—E—升 F、再移到 E—升 F—升 G。第一次移位还在 C 大调内，第二次出现了升 F，第三次出现升 G，耳朵不知不觉已经进入 G 大调的音高范围。若最后落在 G 大调的终止式上，转调就完成了。整个过程没有突兀的「断点」，全靠一次次移位累积。

和声也可以模进。把一个「主—属」的两和弦片段连续上移：C—G，D—A，E—B……每移一次，调性重心就往上挪一点。这种写法在展开性段落里尤其常见：音乐需要「走起来」，又不想突然插入新调，模进提供了最平滑的方案。使用时要留意别移得太远，否则听众会失去调性参照；适可而止，再落回一个明确的终止式，效果最好。

模进的「度」也要拿捏。移位的音距越小，越像在原调里打转；音距越大，越容易一下子跳到远关系调。常见的做法是每次上移二度或三度，连续两三次后收住——既走出了距离，又不至于失控。若一路移个五六次，调性会变得飘忽，听众反而抓不住主线。一句老经验是：模进要「走得动、收得回」，收得回靠的还是那句目标调的终止式。

> 分歧｜模进算不算「独立的转调手法」，教学口径不一。有的教材把它列为转调方法之一，强调「连续移位即可转调」；有的教材认为模进只是材料发展手段，真正决定调性的仍是中介和弦与终止式。本章采取折中说法：模进负责把音乐「带过去」，中介和弦与终止式负责让她「站住」，两者配合才算完整的转调。

## 八、转调和离调到底差在哪里

上一章讲过离调，这里是把它们放在一起比较的好时机。两者都借别调的和弦、都出现变化音，表面很像；差别要看三件事。第一，时长：离调常常只有一小节甚至几拍，转调则在目标调里停留至少一个乐句。第二，落点：离调的目标和弦通常还是本调内的级数，转调的目标则成为新的主音并建立自己的终止式。第三，回归：离调几乎必然回到原调，转调则在新调继续发展，有时到段落结束也不回去。

用一句话概括：离调是「去邻居家串门」，转调是「搬家」。串门再久，钥匙还在自己家；搬家则连户口都迁走了。这把尺子在 M3-12 讲调关系时已经埋下，这里把它用起来——判断时先问「有没有新调的终止式」，再问「新调待了多久」，两条一问，通常就能定案。

边界情形确实存在。一个较长的离调，可能持续两三个小节并出现目标调的属七，看起来很像转调；一个短的转调，也可能只有一两句就转回来。遇到这类情形，本章建议如实标注「介于两者之间」，并说明判断依据是「是否建立了新调的终止式」，而不是硬贴一个标签。诚实描述现象，比强行归类更有价值。

## 九、转调在音乐里做什么，发展与对比

转调最直接的用途是制造对比。一段音乐若始终在一个调里，色彩单一；中段转到近关系调，听众会感到「换了一口气」，回到原调时又有「回家」的亲切。许多小型曲式的中段都这么写：主题在原名，中部转到属调或关系小调，再现部回到原调——一去一回，结构就有了起伏。

第二个用途是发展乐思。前面说过，模进能把一个短片段连续移位、逐步走远；转调则把这种「走远」固定下来，让主题在新的调性环境里重新出现。同一个动机，在原调是明亮的，转到关系小调就带上一层柔和，听众认得出旋律，却感到情绪变了。这是作曲家最经济的「变奏」手段之一。

第三个用途是推进张力。越往远关系调走，调性色彩差异越大，紧张感越强；因此转调常被放在乐句的高潮之前，把音乐推到一个更远的地方，再通过转回原调释放这份张力。理解这一点，再听那些「中段忽然远去、结尾又稳稳回来」的段落，就能明白它不是随意为之，而是有明确的结构目的。

把三种用途合起来，会给听者一个实用的提示：遇到转调，先别急着判断「好不好听」，而问「它在结构里做什么」。是给中段制造对比？是把主题换个色彩再呈现一次？还是为高潮积攒张力？问题一变，听到的东西就不同——同样一次转调，从结构角度看和从色彩角度看，会得到两份互补的理解。这也是本系列一直强调的：先说清「是什么、在哪里」，再谈「好不好」。

> 边注｜浪漫主义时期的作曲家越来越偏爱远关系转调，因为近关系调的对比太温和，不够表达剧烈的情绪起伏。这种倾向与本系列 M1 讲的浪漫主义一脉相承：形式上的扩张，往往对应着情感表达需求的扩张。下一章讲的等音转调，正是把这种「走远」推到极致的技术。

## 十、本章要点

1. 移调是全曲整体平移，转调是作品中途从一调进入另一调并继续发展；本章讲后者。
2. 转调搬的是主音、调号与调式色彩，其中新主音能否稳定落地是判断「到家」的核心。
3. 近关系调指调号相差不超过一个升降号的调；C 大调的近关系调有 G、F、a、e、d 五个。
4. 共同和弦在两调中音高相同、身份不同，充当转调的桥；它身兼两职，被「重新解释」后完成过渡。
5. 中介和弦优先选在目标调中功能明确者，并紧接目标调的属七与终止式；声部尽量平顺。
6. 转调五步：定目标、找共同和弦、派新角色、接目标属七、用目标终止式收住；缺最后一步便站不稳。
7. 模进是把同一材料移到另一音高重复，分上行/下行、严格/自由、调内/转调等类型。
8. 转调模进靠连续小步移位累积距离，把音乐带进新调；仍需中介与终止式让她真正站住。
9. 转调与离调的分别在于时长、落点与是否回归；判断的硬标准是「是否建立新调的终止式」。

转调让音乐在近关系调之间稳稳地搬家；可有些作品要走得更远，近关系的桥够不着。下一章讲变和弦与等音转调，看作曲家怎样用同一个音响的「两种写法」，一步跨到远关系调。
